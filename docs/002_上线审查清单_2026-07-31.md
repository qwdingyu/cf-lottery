## 一、安全审查

### 1.1 认证与授权
- [x] JWT_SECRET 无硬编码回退，未配置时抛出 500
- [x] 密码强度：≥8 位 + 字母数字组合
- [x] 用户名格式：字母数字下划线，2-40 字符
- [x] 登录使用恒定时间返回，防止用户名枚举
- [x] 检查用户状态（active/suspended）
- [x] 所有管理端路由使用 requireAuth 中间件
- [x] 管理端查询按 tenant_id 过滤
- [ ] 未实现：登录失败次数限流（防暴力破解）
- [ ] 未实现：session 撤销机制（JWT 无法主动撤销）
- [ ] 未实现：CSRF 保护

### 1.2 密码存储
- [x] 使用 PBKDF2 + SHA-256 × 100000 迭代
- [x] 随机盐值（16 字节）
- [ ] 建议升级：Argon2id 或 bcrypt（084 文档要求）

### 1.3 API 安全
- [x] CORS 中间件已配置
- [x] 全局错误处理中间件（不暴露堆栈）
- [x] 验证码 hash 存储（SHA-256）
- [x] 验证码 10 分钟有效期
- [x] 公开活动使用不可枚举 public_slug
- [x] 邮箱脱敏展示
- [ ] 未实现：IP 限流（登录/注册/验证码发送）
- [ ] 未实现：请求体大小限制
- [ ] 未实现：HTTPS 强制（依赖 Cloudflare）
