# 277 Web 端活动创建页动态列表样式失真排查与修复

> 日期：2026-08-29  
> 背景：运营在 Web 端创建活动时，高级配置区「引擎推荐奖励/裂变」动态添加行出现样式失真；  
> 用户要求以「奖项配置」为唯一参照做全局梳理，不要局部打补丁。

---

## 一、根因

| 区块 | 根因 | 表现 |
|------|------|------|
| 引擎推荐奖励 | 使用 `flex` 行 + 固定宽度，动态的 `small` 警告文本成为隐式子项 | 长文案、窄弹窗、券标签字段出现时，删除按钮和输入框横向漂移 |
| 奖项配置 | 使用 `grid` + 表头/数据行共享列轨道 | 样式稳定，不受内容长度影响 |
| 其他动态行 | 投票选项/问卷字段/秒杀阶梯已有网格或折叠处理，未发现同类根因 | — |

---

## 二、修复

1. **统一列轨道**：裂变奖励行从 `flex` 改为与奖项配置一致的显式 Grid，表头与数据行共用 5 列轨道。
2. **固定警告位置**：数值警告不再参与 flex 分布，始终落在「奖励类型」列下方，不挤占券标签和删除按钮。
3. **窄屏重排**：`<=720px` 时隐藏表头，数据行显式 3 列 + 全宽字段，避免隐式列。

---

## 三、同类审查结论

已核对同页所有 `v-for` 动态行：
- 奖项配置 `tier-row`：已有 Grid 列轨道，无需改动。
- 投票选项 `activity-config-row` / `choice-option-row`：使用 `form-grid two-cols` 网格，结构稳定。
- 问卷字段 `survey-field-*`：头部+详情折叠，结构稳定。
- 秒杀阶梯 `flash-sale-tier-row`：`flex-wrap` label，已有换行兜底，未发现同类问题。
