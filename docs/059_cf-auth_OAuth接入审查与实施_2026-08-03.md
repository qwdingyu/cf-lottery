## 一、审查结论：cf-lottery 现有认证面

| 路径 | 位置 | 作用 | 本轮 |
|------|------|------|------|
| 管理端用户名密码 + 邮箱验证码注册 | `src/routes/auth.ts` register/login/verify-email | L2 租户账号；`PASSWORD_PEPPER` + 自签 JWT | **保留** |
| `requireAuth` / `requireTenantMember` | `src/middleware/auth.ts` | Bearer JWT（HS256 + `JWT_SECRET`） | **保留**；cf-auth 交换后仍发同类 JWT |
| 公开参与邮箱验证码 / roster / password / invite | `public-lottery` + 前端 | 活动参与身份，非管理 JWT | **保留** |
| ~~Logto ID Token → 自签 JWT~~ | ~~logto-auth + logto-exchange~~ | 半成品双轨 | **已删除**（见 docs/061） |
| Better Auth 根项目 smoke | `src/better-auth-smoke.test.ts` / docs/056 | **仅技术验证**，不是多项目主登录态 | **不**当接入形态；不嵌进 lottery 当 IdP |
| **cf-auth OAuth RP** | `src/lib/cf-auth-oauth.ts` + `/api/auth/cf-auth/*` | 授权码 + PKCE → userinfo → 业务 JWT | **唯一外部 IdP 路径（可开关）** |

### 与 cf-auth 的边界（冻结）

```text
cf-auth (IdP, 本地 :8788 / 生产 auth.eforge.xyz)
  授权码 + PKCE + openid profile email
        │
        ▼
cf-lottery (RP)
  - 自己的业务 JWT（JWT_SECRET）
  - 自己的用户/参与映射（sub = cf-auth 的 sub，email 来自 userinfo）
  - 不共享 Better Auth session cookie
  - 不直连 auth 数据库
```

| 做 | 不做 |
|----|------|
| 标准 OAuth 授权码 + PKCE | 跨项目共享 session cookie |
| code → token → userinfo → lottery 自签 JWT | lottery 直连 cf-auth SQLite/D1 |
| env 开关 `CF_AUTH_ENABLED` | 再引入第二套托管 IdP（Logto 已移除，见 061） |
| 参与端 + 管理端 cf-auth 按钮 | 真实 Google 浏览器同意页 E2E（依赖 IdP 侧） |
| | 全局 SLO、公网动态 client 注册 |
| | 用根项目 Better Auth 替代 cf-auth |

### 风险

- cf-auth **生产 IdP（auth.eforge.xyz）已可访问**（2026-08-03 实测 ok + OIDC discovery）；**lottery 生产 RP 仍可能未配**（见 docs/065：meta HTML、`invalid_client`、无 `CF_AUTH_*` secret）。
- client_secret 仅存 lottery 服务端 env，禁止下发浏览器。
- PKCE `code_verifier` 由前端会话级持有并在 exchange 时提交；`state` 防 CSRF。
- 身份映射以 **docs/062** 为准（JWT.sub = 本地 users.id），059 初稿「sub=上游 sub」已废弃。

## 二、接入设计（已实现）

### 环境变量（lottery）

| 变量 | 说明 |
|------|------|
| `CF_AUTH_ENABLED` | `true`/`1` 开启；缺省关闭 |
| `CF_AUTH_ISSUER` | 如 `http://localhost:8788`（无尾斜杠） |
| `CF_AUTH_CLIENT_ID` | OAuth client id |
| `CF_AUTH_CLIENT_SECRET` | OAuth client secret（仅服务端） |
| `CF_AUTH_REDIRECT_URI` | 如 `http://localhost:8787/auth/callback` |
| `CF_AUTH_SCOPES` | 默认 `openid profile email` |

cf-auth 侧本地注册 client 示例：

```bash
# 在 cf-auth 仓库，服务已起
node scripts/register-oauth-client.mjs \
  --email owner@example.com --password '...' \
  --name cf-lottery-web \
  --redirect http://localhost:8787/auth/callback \
  --skip-consent
```

### API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/auth/cf-auth/meta` | `{ enabled, authorizeUrl, clientId, redirectUri, scopes, issuer }`（无 secret） |
| POST | `/api/auth/cf-auth/exchange` | body: `{ code, codeVerifier, redirectUri? }` → `{ ok, token, email, sub, idpSub, tenantId, needsTenant }`（`sub`=本地 users.id，见 062） |

### 身份映射（docs/062 起）

- 业务 JWT `sub` = **本地 `users.id`**（exchange 内 `provisionIdpUser` 建档/绑定）
- 业务 JWT `idpSub` = cf-auth userinfo.`sub`（审计；非 requireAuth 主键）
- `email` = userinfo.email（写入/对齐本地用户）
- `tenantId` / `tenantRole`：已有 membership 则带上，否则空串 → `needsTenant` → onboarding
- 公开参与：**必须**写入 `sessionStorage.lottery_registered_token`（+ 可选 `lottery_session_email`）；**仅** `admin_token` 不够

### 参与端闭环（OAuth 往返）

1. 登录弹窗点「统一认证」：跳转前 `missingJoinCredentialForMode` 校验 password/invite；`saveCfAuthPendingJoin`（drawId / 密码 / 邀请码 / returnPath）+ PKCE 后跳转 IdP  
2. 回调 `/auth/callback`：`exchange` → `setToken(admin)` **且** `applyCfAuthSessionToLottery`（`lottery_registered_token`）  
3. 回跳分流：`resolveAdminPathAfterCfAuth` — 目标为 `/admin*` 且 JWT `tenantId` 空 → `/admin/onboarding`；`/lottery*` 不改写  
4. 回活动页：`resumeCfAuthJoinAfterCallback` **只 read pending**；registered 走 access-code，其余走 verify-join + Bearer；**仅 join 成功后 `consume`**（失败保留 pending，可补凭证重试）  
5. UI：`cfAuthEnabled` **不嵌套**在 `logtoEnabled` 内；只开 `CF_AUTH_*` 时参与端仍可见入口  
6. **Logto 已移除**（docs/061）：无 `App.vue` Logto 回调；统一认证仅 cf-auth + 邮箱/密码

### 深审修复点

| 问题 | 修复 |
|------|------|
| resume 开头 `consume`，join 失败后 pending 丢失 | 成功后再 `consume`；失败可 `save` 回写弹窗改过的密码 |
| password/invite 空凭证仍跳 IdP | `handleCfAuthJoin` 跳转前 `missingJoinCredentialForMode` |
| 管理端 cf-auth JWT `tenantId=""` 直进 `/admin` 403 | `resolveAdminPathAfterCfAuth` → onboarding；路由守卫仍兜底 |
| 会话键字符串双源 | LotteryView 统一用 `LOTTERY_*_KEY` 常量 |
| Logto 半成品双轨 | **061 全面删除** SDK / exchange / env |

### 回退

关闭 `CF_AUTH_ENABLED` 或未配齐 client → meta.`enabled=false`，exchange 返回 503；**邮箱码 / 用户名密码登录仍可用**（无 Logto 回退）。
