# 103 开奖后隐藏「分享邀请」

日期：2026-08-04  
触发：已开奖用户打开「我的结果」中奖页，仍显示「分享你的好运，让更多人来参与！」并提供邀请链接。

---

## 1. 为什么不对

| 时机 | 邀请/裂变意义 |
| --- | --- |
| 活动 `open`（可参与） | 有：拉新、加权次数、传播 |
| 活动已 `drawn` / `cancelled` | **无**：别人点开也无法再参与同等机会；推「让更多人来参与」是空头 CTA |

旧逻辑：中奖分支**无条件**渲染 `result-share-win`；`GameResultModal` 参与成功也默认拉分享链接。

---

## 2. 正确规则

```text
shouldShowInviteShareCta(drawStatus) =
  false  if status ∈ { drawn, cancelled, closed }
  true   otherwise（含 open / drawing / paused / 未知）
```

- 「我的结果」中奖：仅 `showMyResultInviteShare` 为真时展示分享块  
- 参与成功弹窗：`drawStatus` 传入后同样门禁；终态不请求 `/share`  
- **中奖后导流 CTA**（`after_win` 外链）保留：那是商品/落地页，不是「邀请参与本活动」

---

## 3. 改动

- `public-helpers.shouldShowInviteShareCta` + 单测  
- `LotteryView` 中奖分享块 `v-if`  
- `GameResultModal` + `lastJoinDrawStatus`

---

## 4. 明确不做

- 不删除分享 API  
- 不在终态伪造「活动仍可参与」文案
