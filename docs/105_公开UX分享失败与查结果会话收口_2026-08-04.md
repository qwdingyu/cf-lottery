## 2. 正确规则

```text
分享 UI 三态互斥（inviteShareAllowed 为真时）
  shareLoaded → 裂变卡 / 分享按钮
  shareError  → 错误文案 + 重试（重试中可 disabled + loading 文案）
  shareLoading && entryId → 「加载分享链接…」
  禁止：失败后仍用 entryId 显示加载句

result_mode = review_decision
  join 成功 hint → joinResultHintReview
  open 已参与横幅 → statusHintJoinedReview
  标签 → adminResultReview（已有）

drawing 横幅
  lottery|claim|缺 kind → statusHintDrawing
  其它 kind → statusHintDrawingGeneric

查结果会话
  JWT → 强会话一键查（docs/084）
  无 JWT + sessionEmail 含 @ → 弱会话：预填邮箱、无码先试；
    失败/网络错 → myResultForceOtpForm=true 展开 OTP
  用户可点「使用其他邮箱或验证码」主动展开
```
