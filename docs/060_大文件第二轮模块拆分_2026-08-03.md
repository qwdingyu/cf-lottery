# 060 大文件第二轮模块拆分

**日期**：2026-08-03  
**范围**：延续 `docs/058`，继续按域拆分，**不过碎**

## 原则（与 058 一致）

1. 后端按 **setup\* 挂载**，一个文件 ≈ 一个业务域，不拆成「一接口一文件」。
2. 前端先抽 **composable / CSS**，父 SFC 保留模板与主流程编排。
3. 目标行数：主文件约 **600–900 行逻辑路由**、Vue 脚本可维护即可；模板可仍偏大。

## 变更结果（约）

| 文件 | 前（本轮起点） | 后 |
|------|----------------|-----|
| `public-lottery.ts` | ~1165 | ~814 + helpers ~173 + share ~234 |
| `admin-lottery.ts` | ~1236 | ~660 + draw-ops ~612 |

### 后端新增

- `src/routes/public-lottery-helpers.ts` — 限流、身份、验证码、脱敏、JSON/HTML 工具
- `src/routes/public-lottery-share.ts` — `setupPublicShareRoutes`：接龙列表 / 裂变排行 / 分享码
- `src/routes/admin-lottery-draw-ops.ts` — `setupDrawOpsRoutes`：中奖、统计、导出、删除、奖项、名单、邀请码等运营数据

主文件保留：

- **public**：活动详情、OG、事件、验证码、参与、查结果、取消
- **admin**：dashboard / me / 活动 CRUD / 发布·暂停·恢复·取消·开奖状态机

### 前端新增

- `frontend/src/views/admin/lottery/usePosterQr.ts` — 本地 QR + 海报截图与缓存
- `frontend/src/views/admin/lottery/useDrawAnalytics.ts` — 漏斗 / 转化分析弹窗
- `frontend/src/views/lottery/lottery-page.css` — 用户端抽奖页样式（SFC `import`，避免 scoped `@import` 丢作用域）
