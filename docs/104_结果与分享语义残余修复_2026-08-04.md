## 2. 正确规则

```text
即时结果 hint ≠ 邀请 CTA
  hint：只陈述结果已就绪 / 可回看
  邀请：仅 shouldShowInviteShareCta(status) 为真时展示按钮/裂变卡

OG description fallback(status)
  drawn|closed → 活动已结束，可查看结果
  cancelled → 活动已取消
  draft|paused → 暂未开放
  drawing → 正在出结果
  其它 → 快来参与（仅可参与语境）

记录「未中奖」标签
  won=false AND status=drawn AND activityKind ∈ {lottery, claim}
  缺 activityKind → 不标未中奖（保守）

已结束横幅
  lottery|claim|缺 kind → statusHintDrawn（可含「是否中奖」）
  其它 kind → statusHintDrawnGeneric（「查询你的结果」）
```
