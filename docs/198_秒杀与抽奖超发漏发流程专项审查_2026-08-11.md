## 2. 抽奖

### 2.1 中奖名额分配（performDraw）

| 路径 | 结论 | 证据 |
|:-----|:----:|:-----|
| 名额上限 | ✅ 不超发 | `for i < tier.winnerCount && entryIndex < selected.length` |
| 不重复中奖 | ✅ 一人一奖 | seenEntryIds 纵深防御 |
| 参与者不足 | ✅ 正常 | randomSelect n = min(count, pool) |
| 码不足 | ✅ 不静默 | 中奖者记录但无码（prizeCodeId 空），可补发 |
| 状态与中奖同事务 | ✅ 不活动自锁 | drawn 与 winners 同事务（#3.4 修复） |

### 2.2 抽选算法

| 算法 | 结论 | 证据 |
|:-----|:----:|:-----|
| randomSelect（等权） | ✅ 无放回+数量受限 | 部分 Fisher-Yates，n=min(count,pool) |
| weightedSampleUnique（裂变） | ✅ 无放回+去重+有界 | pool.splice + seen 去重 + while 上限 |

### 2.3 即时抽奖（spin）

| 路径 | 结论 | 证据 |
|:-----|:----:|:-----|
| 扣次 CAS | ✅ 不扣成负 | UPDATE spinsLeft-1 WHERE spinsLeft>=1 |
| 奖档封顶 | ✅ 不超发 | awardedCount < winnerCount CAS + 失败释放码 |
| 卡密原子锁 | ✅ 不重复 | 子查询选码 + 条件 UPDATE |
| 幂等回放 | ✅ 不重发 | idempotencyKey 唯一 + 回放不重复占码 |

## 4. 结论

**秒杀和抽奖均无超发、无漏发、无流程错误**：
