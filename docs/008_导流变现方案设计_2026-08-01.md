# cf-lottery 导流变现方案设计

> 文档编号：008
> 创建时间：2026-08-01
> 定位：抽奖作为导流工具，实现商品推广、广告变现、转化追踪
> 作者：产品经理 + 市场运营

---

## 一、核心逻辑

**抽奖不是目的，是手段。** 用户参与抽奖的动机是"中奖"，但运营者的目的是"让用户看到商品/广告"。

```
用户参与抽奖 → 完成指定动作（看商品/点链接/关注公众号）→ 获得参与资格 → 开奖
                                                                  ↘ 中奖 → 获得奖品（卡密/优惠券）
                                                                  ↘ 未中奖 → 获得下次参与机会或折扣码
```

---

## 二、导流模式

### 2.1 商品推广模式（最推荐）

**适用场景：** 电商卖家、品牌方、有赞/Shopify 商家

**流程：**
```
运营者创建活动 → 配置关联商品（名称/图片/链接/价格）
→ 发布活动
→ 用户参与时看到商品卡片 → 点击"查看商品"跳转商品页
→ 参与成功 → 开奖
→ 中奖者获得奖品码
→ 未中奖者获得限时折扣码（促进转化）
```

**关键设计：**
- 商品卡片显示在参与成功页，不干扰参与流程
- 点击商品链接使用 `utm_source=lottery` 参数，方便统计
- 未中奖用户自动获得折扣码，促进二次转化

**盈利模式：**
- 按 CPS（按销售额分成）向商家收费
- 或按 CPM（曝光量）收取广告费

### 2.2 社交裂变模式

**适用场景：** 公众号涨粉、社群拉新、品牌曝光

**流程：**
```
用户参与抽奖 → 获得"额外参与次数"或"加倍中奖概率"
→ 分享到微信群/朋友圈 → 好友通过链接参与
→ 分享者获得额外抽奖码
→ 排行榜：邀请最多的人额外奖励
```

**关键设计：**
- 每个参与者生成专属分享链接（含邀请码）
- 通过邀请码追踪邀请关系
- 邀请排行榜实时更新

**盈利模式：**
- 按 CPA（按行动付费）向品牌方收费
- 或按 CPC（按点击付费）收取广告费

### 2.3 广告植入模式

**适用场景：** 品牌广告主、活动赞助商

**流程：**
```
用户参与抽奖 → 参与成功页展示品牌广告横幅
→ 点击广告跳转落地页
→ 观看广告视频（可选）可获得额外参与次数
```

**广告位设计：**
- 参与成功页顶部横幅（728×90）
- 开奖结果页底部广告
- 邮件通知中嵌入商品推荐

**盈利模式：**
- 按 CPM（千次曝光）收费
- 按 CPC（单次点击）收费

### 2.4 本店促销模式

**适用场景：** 自家店铺促销、老客回馈

**流程：**
```
用户购买商品 → 订单完成页推送"免费抽奖"
→ 参与抽奖 → 100% 中奖（优惠券/满减券）
→ 优惠券自动发放到用户账户
→ 下次购物时自动抵扣
```

**关键设计：**
- 抽奖入口在订单完成页
- 奖品是优惠券，100% 中奖
- 优惠券有使用门槛和有效期

## 三、数据模型扩展

### 3.1 活动关联商品

```typescript
// lottery_draws 扩展字段
productLink: {
  url: string        // 商品链接
  title: string     // 商品名称
  imageUrl: string  // 商品图片
  price: string     // 展示价格
  utmSource: string // 追踪参数（默认 lottery）
}
```

### 3.2 转化追踪

```typescript
// 新增：lottery_clicks（点击追踪）
{
  id: string
  drawId: string
  entryId: string           // 关联的参与记录
  clickType: 'product' | 'ad' | 'share'
  targetUrl: string         // 点击的目标链接
  utmSource: string
  ipHash: string
  clickedAt: string
}

// 新增：lottery_coupons（未中奖优惠券）
{
  id: string
  drawId: string
  entryId: string
  code: string              // 优惠券码
  discount: string          // 折扣说明（如"满100减20"）
  expiresAt: string         // 有效期
  status: 'active' | 'used' | 'expired'
  createdAt: string
}
```

### 3.3 分享追踪

```typescript
// lottery_draws 扩展字段
shareConfig: {
  enabled: boolean          // 是否开启分享裂变
  extraEntriesPerShare: number  // 每次分享获得的额外参与次数
  maxExtraEntries: number   // 最多额外次数
  shareMessage: string      // 分享文案
}

// 新增：lottery_shares（分享记录）
{
  id: string
  drawId: string
  entryId: string           // 分享者
  shareCode: string         // 分享码（用于追踪）
  shareType: 'wechat' | 'weibo' | 'copy_link'
  clickedCount: number      // 被点击次数
  joinedCount: number       // 通过此链接参与的人数
  createdAt: string
}
```

## 六、追踪与数据

### 6.1 UTM 参数

所有出站链接自动附加 UTM 参数：

```
https://shop.example.com/product/123
  ?utm_source=lottery
  &utm_medium=draw
  &utm_campaign={draw_id}
  &utm_content={entry_id}
```

### 6.2 转化漏斗

```
参与 → 看到商品 → 点击商品 → 查看详情 → 购买
  ↓       ↓          ↓          ↓          ↓
100%    80%        12%        8%         3%
```

### 6.3 数据看板指标

| 指标 | 说明 | 计算方式 |
|------|------|---------|
| 参与人数 | 总参与次数 | COUNT(entries) |
| 商品曝光 | 参与成功页展示次数 | COUNT(draws with product_link) |
| 商品点击 | 商品链接点击次数 | COUNT(clicks WHERE click_type='product') |
| 点击率 | 商品点击/曝光 | click_count / impression_count |
| 分享次数 | 分享链接生成次数 | COUNT(shares) |
| 裂变系数 | 通过分享带来的新参与 | share_joined_count / share_count |
| 优惠券发放 | 未中奖优惠券发放数 | COUNT(coupons) |
| 优惠券使用 | 优惠券已使用数 | COUNT(coupons WHERE status='used') |
| 预估 GMV | 预估成交金额 | click_count × 平均转化率 × 客单价 |

## 七、实施建议

### 7.1 MVP 阶段（当前版本，不做导流）

**原因：** 核心抽奖功能尚未打磨成熟，不应过早加入商业化功能。

### 7.2 第一阶段：商品链接（推荐先做）

**预估工时：** 3-5 天
**改动范围：**
- 后端：`lottery_draws` 扩展 `product_link` 字段 + `lottery_clicks` 表
- 前端：参与成功页展示商品卡片
- 管理端：活动创建页添加商品配置

### 7.3 第二阶段：未中奖优惠券

**预估工时：** 2-3 天
**改动范围：**
- 后端：`lottery_coupons` 表 + 开奖后自动发放逻辑
- 前端：开奖结果页展示优惠券

### 7.4 第三阶段：分享裂变

**预估工时：** 3-5 天
**改动范围：**
- 后端：`lottery_shares` 表 + 分享码生成 + 额外参与次数逻辑
- 前端：分享弹窗 + 邀请排行榜

### 7.5 第四阶段：数据看板

**预估工时：** 2-3 天
**改动范围：**
- 后端：统计 API
- 前端：数据看板页面

## 八、总结

**抽奖是手段，不是目的。** cf-lottery 的核心价值不仅是"帮人抽奖"，更是"帮人通过抽奖获得流量和转化"。

| 模式 | 难度 | 价值 | 推荐度 |
|------|------|------|:------:|
| 商品链接推广 | 低 | 高 | ⭐⭐⭐⭐⭐ |
| 未中奖优惠券 | 低 | 中 | ⭐⭐⭐⭐ |
| 分享裂变 | 中 | 高 | ⭐⭐⭐⭐ |
| 广告位 | 中 | 中 | ⭐⭐⭐ |
| 数据看板 | 低 | 高 | ⭐⭐⭐⭐⭐ |

**建议优先实现商品链接 + 数据看板，其次是未中奖优惠券和分享裂变。广告位可以放在最后，因为需要建立广告主生态。**
