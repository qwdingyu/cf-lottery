# 首页登录态店铺入口国际化修复

## 背景

生产首页 `https://lucky.eforge.xyz/` 登录后右上角店铺入口显示 `landing.myShop`，说明 Vue i18n 没有在 `landing` 命名空间下找到对应文案。

## 原因

`LandingView.vue` 已正确使用 `$t('landing.myShop')`，但 `zh-CN.ts` 和 `en.ts` 只在 `onboarding.myShop` 下维护了文案。首页导航属于 Landing 页面，不能依赖 onboarding 命名空间。

## 解决方案

- 在 `landing` 命名空间补齐 `myShop`
- 新增 `landing-nav.test.ts` 锁住登录态导航关键文案，避免再次回退显示原始 key

## 验证

- `npx tsc --noEmit`
- `cd frontend && npx vue-tsc -b --pretty false`
- `npx vitest run`
