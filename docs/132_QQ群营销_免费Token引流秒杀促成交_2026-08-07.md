# 132 免费Token引流+秒杀促成交 QQ群营销方案

> 日期：2026-08-07
> 定位：虚拟产品（Token/API Token）的私域营销实操方案
> 依托：cf-lottery 现有能力（大转盘 wheel + 秒杀 flashSale + 卡密 prizeCodes + 导流 CTA + 裂变 viral）
> 场景：Token 免费（大转盘每日发放引流），靠秒杀活动销售（促成交）

## 1. 业务模型：免费引流，秒杀成交

```
┌──────────────────────────────────────────────────────────────┐
│  免费的 Token = 引流诱饵（大转盘每日发放，边际成本≈0）          │
│  付费的 Token = 成交主品（秒杀限时限量，制造稀缺）              │
└──────────────────────────────────────────────────────────────┘

转化漏斗：
  进入QQ群 → 大转盘抽免费Token → 体验Token价值 → 免费Token告急
           → 秒杀推送 → 付费Token成交 → 复购/群扩散
```

**核心逻辑**：Token 是虚拟产品，赠送成本极低，但能建立"价值认知"（用户用过才知道值钱）。免费发放建立信任与依赖，秒杀用稀缺性完成付费转化。

## 2. QQ 群生态分析（为什么选 QQ 群）

| QQ 群特性 | 营销价值 |
| --- | --- |
| **群公告** | 每日活动预告、规则说明、秒杀倒计时 |
| **群机器人** | 定时@全员提醒转盘/秒杀、自动发活动链接 |
| **群文件** | 使用教程、Token 价值演示、客户案例 |
| **群投票** | 收集用户需求、币种偏好、定价敏感度 |
| **群活跃激励** | 签到、邀请进群送转盘次数 |
| **群等级/头衔** | 老用户身份感，促进留存 |

**QQ 群是私域流量池**：相比公域投放，QQ 群转化路径短（群公告→链接→参与），且可反复触达（每日活动预告）。

## 3. 每日运营 SOP（可执行清单）

### 09:00 早间预告
- [ ] 群公告更新：今日大转盘场次 + 秒杀场次预告
- [ ] 群机器人发"今日福利"卡片（转盘链接 + 秒杀倒计时）
- [ ] 强调"免费 Token 每日限量，先到先得"

### 12:00 午间转盘（免费 Token 发放）
- [ ] 发布大转盘链接（分场：12:00 场）
- [ ] 引导用户参与 → 抽免费 Token → 卡密发放
- [ ] 群内晒单（中奖者分享，制造从众）

### 15:00 价值教育
- [ ] 群文件更新：Token 价值案例（省多少钱/提多少效）
- [ ] 群投票：征集下一期秒杀档位/价格偏好
- [ ] 引导新用户"先用免费的，觉得好再买"

### 19:00 秒杀预告（稀缺感）
- [ ] 群公告：今晚秒杀场次、限量、低价
- [ ] 群机器人@全员："免费额度今天将用完，秒杀补货"
- [ ] 倒计时海报/文案

### 21:00 秒杀开抢（促成交）
- [ ] 发布秒杀链接（分场：21:00 场）
- [ ] 强调"限量 N 份，售完即止"
- [ ] 成交后群内引导（晒单/好评）

### 22:00 复盘
- [ ] 记录：进群数、转盘参与数、免费发放量、秒杀成交数、转化率
- [ ] 调整：免费额度/秒杀档位/价格

## 4. 免费 Token 引流设计（大转盘）

### 玩法
- **每日分场**：12:00 / 20:00 两场转盘，每场限量免费 Token
- **免费额度**：每账号每日限领 1 次（防薅羊毛，用 `maxPerUser` / 转盘参与限制）
- **卡密发放**：cf-lottery `prizeCodes` 自动发卡，邮件/页面展示
- **裂变**：转盘参与后生成分享链接，邀请 1 人进群/参与 +1 次转盘机会（`viral` 裂变）

### 免费额度梯度（制造"不够用"依赖）
| 档位 | 免费额度 | 用途 |
| --- | --- | --- |
| 体验档 | 少量 Token | 让用户"尝到甜头"，建立价值认知 |
| 日常档 | 每日限量 | 维持日活，形成"每天来领"习惯 |
| 不满足档 | 一旦用完 | 触发"额度不够"→ 秒杀转化 |

**关键**：免费额度要"够体验、不够用"——太少没价值感，太多没购买动机。

## 5. 秒杀促成交设计（付费 Token）

### 秒杀玩法
- **分场**：每日 1-2 场（19:00/21:00），限时限量
- **档位**：多档 Token 套餐（试水档/常用档/囤货档），主力推荐常用档
- **价格**：秒杀价 = 日常价 x 折扣（7-8 折），制造"错过等明天"紧迫感
- **限量**：`flashSale.stockLimit` 控制，进度条展示"剩余 N 份"

### 成交钩子
1. **免费告急**：免费 Token 将用完时，页面/群内提示"补货请用秒杀"
2. **稀缺倒计时**：秒杀场倒计时 + 剩余份数，制造心急
3. **限时专属**：群内专属秒杀链接（仅群员可见，强化归属感）
4. **晒单激励**：购买后晒单返小奖励（复购抵扣/免费抽奖次数）

## 6. 转化漏斗与数据指标

```
进群 → 参与转盘 → 领免费Token → 体验 → 秒杀点击 → 成交
  ↓        ↓          ↓          ↓       ↓        ↓
进群数    参与率    领取率     留存率  秒杀点击率  转化率
```

| 指标 | 目标 | 优化动作 |
| --- | --- | --- |
| 进群 → 参与转盘 | ≥ 40% | 群公告/机器人触达,链接直达 |
| 转盘 → 领 Token | ≥ 90% | 参与即发,流程顺畅 |
| 领 Token → 次日留存 | ≥ 30% | 每日开场次,形成习惯 |
| 免费告急 → 秒杀点击 | 有免费用完用户 | 群内精准推送 |
| 秒杀点击 → 成交 | ≥ 15% | 价格/稀缺/信任 |

## 8. 合规与风险

| 风险 | 应对 |
| --- | --- |
| 免费 Token 被薅羊毛 | `maxPerUser` 限 1 次 + 每日限量 + 邀请真人验证 |
| 秒杀价过低损利 | 价格下限校验 + 档位梯度（试水档引流） |
| QQ 群广告骚扰 | 每日固定节奏 + 内容价值导向（教程/案例） |
| 用户流失 | 每日分场形成习惯 + 群活跃激励 + 晒单氛围 |
| 支付/卡密异常 | cf-lottery 订单状态机 + 卡密原子发放 + 对账 |

## 10. 结论

**核心打法**：QQ 群私域 + 大转盘免费 Token 引流（建立价值认知与日活）+ 秒杀付费 Token 促成交（稀缺性转化）。免费额度"够体验不够用"是关键——既留住日活，又制造付费动机。cf-lottery 现有能力（转盘/秒杀/卡密/裂变/导流）已覆盖全部营销动作，无需额外开发，落地重点是**每日运营 SOP 和数据复盘**。
