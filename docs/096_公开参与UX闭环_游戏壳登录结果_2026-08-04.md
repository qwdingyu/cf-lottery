# 096 公开参与 UX 闭环：游戏壳 / 登录 / 结果

日期：2026-08-04  
触发：继续「死磕用户体验、闭环、丝滑」；接 095 残留（Form/Submit/Reveal 反馈、无壳体验、查结果断点）。

## 1. 问题与闭环目标

| 断点 | 用户感受 | 本波收口 |
| --- | --- | --- |
| list/queue/calendar/checkin/ballot 无 GameRegistry | 无主 CTA 或底部第二路径混乱 | 别名 → Submit/Form；未知 → Submit 回退 |
| Form/Submit/Reveal 提交无视觉反馈 | 像点了没反应 | loading 脉冲 + spinner；`prefers-reduced-motion` |
| 已参与仍显示「立即参与」灰钮 | 语义撒谎 | `gameSubmitJoined` |
| 仅登录硬跳 `/admin/login` | 打断活动心智 | 优先本页 cf-auth，管理端次要 |
| 已登录只缺密码/邀请码仍走邮箱 OTP | 重复验证 | `pendingJoinCredentialOnly` 只补凭证 |
| 参与成功弹窗只有「知道了」 | 不知道下一步 | 「查我的结果」→ openMyResult |
| 参与记录只展示标签 | 无法一键查结果 | 行可点 → my-result |

## 2. 改动清单

### 游戏壳

- `GameRegistry`：`list`/`queue`/`calendar`/`checkin` → Submit；`ballot` → Form；未知小写归一 + Submit 回退
- `hasRegisteredGameExperience`：显式映射查询（单测）
- `FormGame` / `SubmitGame` / `RevealGame`：loading 态 + 已参与文案
- `activity-defaults` 注释：默认体验须可被 Registry 解析

### 登录与参与

- 仅登录：`handleCfAuthLoginOnly` + `loginOnlyHint` / `loginViaAdmin`
- 凭证-only：`handleCredentialJoinWithBearer`（JWT + 密码/邀请码，免 OTP）
- `gamePrimaryCtaHintKey`：ballot/list/queue/calendar/checkin 对齐壳

### 结果闭环

- `GameResultModal`：`query-result` 事件；非「即时+已有 outcome」展示查结果 CTA
- `LotteryView.onResultModalQuery` → 关弹窗 + `openMyResult`
- 参与记录行 `openMyResultFromRecord` + 样式

### i18n

- 去重重复 `gameFormHint`；新增 `gameSubmitJoined`、`loginOnlyHint`、`loginViaAdmin`、`credentialOnlyHint`
