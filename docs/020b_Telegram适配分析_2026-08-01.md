## 一、Telegram Mini App 适配要点

### 1.1 主题适配

Telegram 提供 `themeParams`，需要映射到 CSS 变量：

```css
:root {
  --tg-bg: var(--tg-theme-bg-color, #1e293b);
  --tg-text: var(--tg-theme-text-color, #f1f5f9);
  --tg-hint: var(--tg-theme-hint-color, #94a3b8);
  --tg-link: var(--tg-theme-link-color, #3b82f6);
  --tg-btn: var(--tg-theme-button-color, #3b82f6);
  --tg-btn-text: var(--tg-theme-button-text-color, #fff);
}
```

### 1.2 导航适配

| 功能 | 说明 |
|------|------|
| BackButton | 活动页返回按钮，调用 `webApp.BackButton.onClick` |
| MainButton | 参与按钮可用 `webApp.MainButton.setText('参与抽奖').show()` |
| 底部安全区 | `padding-bottom: env(safe-area-inset-bottom)` |

### 1.3 交互适配

| 功能 | 说明 |
|------|------|
| 触摸反馈 | 按钮需要最小 44px 触摸区域 |
| 滚动优化 | 使用 `-webkit-overflow-scrolling: touch` |
| 弹窗 | 避免 `position: fixed` 在 WebView 中的问题 |
| 分享 | 使用 `webApp.openTelegramLink` 分享 |
