# 208 平台助手页下拉框样式统一与平台动态标签修复 — 2026-08-12

## 背景

`/admin/platform-targets`（平台助手）页面在通用化（docs/199）重构后，仍存在两个遗留问题：

1. **下拉框样式不符合项目规范**：工具栏筛选下拉框使用了自定义的 `form-select form-select-sm` 类 + 内联样式，而全后台统一的做法（参照 `/admin/draws`）是使用原生 `<select>` 配合共享的 `admin-primitives.css` 渲染。这是典型的"重复造轮子"。
2. **平台选择后标签不切换**：表单中目标 ID / 目标名称的标签硬编码为 "QQ 群号"，选择 Telegram 后仍显示 QQ 文案，不符合多平台通用化的语义。

## 原因

`AdminPlatformTargetView.vue` 在从 `AdminQqAssistantView.vue` 重命名通用化的过程中，只改了路由和 i18n 命名空间，但模板结构、控件样式和平台特定文案仍沿用 QQ 时代的实现。

- 表单控件类 `form-input` / `form-select` / `form-hint` 是 scoped 自定义样式，与共享 primitives 重复。
- 目标 ID 标签直接写死 `labelGroupId`（"QQ 群号"），没有根据 `form.platform` 动态切换。

## 排查过程

- 对比 `AdminLotteryView.vue`（/admin/draws）：工具栏用原生 `<select>`，弹窗用 `modal-form` + `<label><span>…</span><input/></label>` 结构，控件样式由 `@import '@/assets/admin.css'` 提供。
- 对比 `AdminBlacklistView` / `AdminMembersView` / `AdminIntegrationsView`：弹窗统一 `div.modal-form > label > span + input`。
- 确认 `adminPlatformTarget.labelGroupId` i18n 键只有一个（QQ），无 Telegram 版本。

## 解决方案

### 1. 下拉框样式统一（参照 /admin/draws）

- 工具栏筛选：移除 `class="form-select form-select-sm"` 和内联 `style`，改为原生 `<select>` + `:aria-label`。
- 弹窗表单：移除所有 `form-input` / `form-select` / `form-hint` 自定义类，改用共享 `modal-form` + `<label><span>…</span><input/></label>` 结构，提示用 `<small class="field-hint">`。
- scoped `<style>` 移除 `.form-input` / `.form-select` / `.form-textarea` / `.form-hint` 这些与共享 primitives 重复的样式定义，仅保留页面特有结构类（`.form-group` 间距、`.form-fieldset`、`.checkbox-group`、`.secret-box` 等）。

### 2. 平台动态标签

在 `<script setup>` 中新增 4 个 computed：

```ts
const targetIdLabel = computed(() =>
  form.value.platform === 'telegram' ? t('adminPlatformTarget.labelTelegramTargetId') : t('adminPlatformTarget.labelGroupId'))
const targetIdPlaceholder = computed(() =>
  form.value.platform === 'telegram' ? t('adminPlatformTarget.placeholderTelegramTargetId') : t('adminPlatformTarget.placeholderGroupId'))
const targetNameLabel = computed(() =>
  form.value.platform === 'telegram' ? t('adminPlatformTarget.labelTelegramTargetName') : t('adminPlatformTarget.labelGroupName'))
const targetNamePlaceholder = computed(() =>
  form.value.platform === 'telegram' ? t('adminPlatformTarget.placeholderTelegramTargetName') : t('adminPlatformTarget.placeholderGroupName'))
```

i18n 新增 Telegram 专用键（zh/en）：`labelTelegramTargetId`、`placeholderTelegramTargetId`、`labelTelegramTargetName`、`placeholderTelegramTargetName`。
