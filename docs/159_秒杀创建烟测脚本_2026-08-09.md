# 秒杀创建烟测脚本

## 目标

用真实 API 串起秒杀草稿创建、阶梯价配置、卡密奖品池、发布前检查，先验证“秒杀创建链路”本身，再单独进入支付测试。

## 脚本

`scripts/05-smoke-flash-sale.mjs`

## 覆盖范围

1. 登录并创建租户
2. 创建秒杀草稿
3. 配置 `promotionConfig.flashSale`
4. 创建 code 奖品并导入卡密
5. 绑定奖项 tier
6. 调用 publish-check 验证发布前条件

## 默认策略

- 默认 `paymentRequired=false`
- 先验证秒杀与阶梯价，不把支付配置提前引入
- 通过后再单独测试支付路径

## 运行方式

```bash
SMOKE_BASE_URL='http://localhost:8787' \
SMOKE_DATABASE_URL='file:./data/flash-sale-smoke.db' \
ADMIN_PASS='Smoke1234A!' \
node scripts/05-smoke-flash-sale.mjs
```

说明：

- `SMOKE_BASE_URL` 和 `SMOKE_DATABASE_URL` 必须显式指向本地烟测环境
- `ADMIN_PASS` 可用于已有本地账号；不传时脚本会在本地库里自动 bootstrap
- `FLASH_SALE_PAYMENT_REQUIRED=true` 仅在后续测试支付前提时使用
