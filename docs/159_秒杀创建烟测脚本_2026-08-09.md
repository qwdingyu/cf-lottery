# 秒杀创建烟测脚本

## 目标

用真实 API 串起秒杀草稿创建、阶梯价配置、卡密奖品池、发布前检查，先验证“秒杀创建链路”本身，再单独进入支付测试。

## 脚本

`scripts/05-smoke-flash-sale.mjs`

## 覆盖范围

1. 登录并创建租户
2. 创建秒杀草稿
3. 配置 `promotionConfig.flashSale`
4. 创建 code 奖品并导入卡密
5. 绑定奖项 tier
6. 调用 publish-check 验证发布前条件

## 默认策略

- 默认 `paymentRequired=false`
- 先验证秒杀与阶梯价，不把支付配置提前引入
- 通过后再单独测试支付路径

## 运行方式

```bash
ADMIN_PASS='你的密码' node scripts/05-smoke-flash-sale.mjs
```
