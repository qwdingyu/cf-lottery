# 098 无 JWT 回访「已参与」提示与纯函数抽取

日期：2026-08-04  
前置：097 落地了 JWT 静默 my-result、myEntryList 最小写入、silent 轮询、409 友好路径。  
缺口：open 邮箱 OTP 参与后**常无业务 JWT**，刷新后 `myJoinedById` 仍空 → 再点参与 → 409。

---

## 1. 问题（证据）

| 路径 | 刷新后 | 根因 |
| --- | --- | --- |
| registered / cf-auth / admin 同步 | 有 `lottery_registered_token` | 097 `hydrateJoinedStateFromSession` 已覆盖 |
| open + 邮箱 OTP | 往往只有 `sessionEmail` | **无 JWT** → my-result 不调 → UI 像未参与 |

本机「已参与」**不是**密码学证明，也不能代替查结果 OTP 读卡密；只服务：灰钮、已参与标签、状态句、避免把 409 当首次失败。

---

## 2. 方案

### 2.1 `frontend/src/views/lottery/joined-session.ts`

| 导出 | 作用 |
| --- | --- |
| `LOTTERY_JOINED_HINTS_KEY` | sessionStorage 键 |
| `upsertJoinedHint` / `readJoinedHints` / `clearJoinedHints` | slug+id 双键写入/读/清 |
| `isAlreadyJoinedResponse` | 409 与中英文案 |
| `resolvePublicDrawPathKey` | 公开 API 优先 publicSlug |
| `joinResultHintI18nKey` / `joinedOpenStatusHintKey` | result_mode 诚实分支 |
| `isSilentFetchOption` | 忽略模板 @click 的 Event |

### 2.2 LotteryView 接入

- `markDrawJoined`：写 `myJoinedById` + `myEntryList` + **upsertJoinedHint**（含 entryId/won 可选）
- `hydrateJoinedStateFromSession`：先读 hints 回填；有 JWT 再静默 my-result 权威确认
- 本地重复 `isAlreadyJoinedResponse` / silent 判定改为 import
- `statusPathHint`：已参与 + open 走 `joinedOpenStatusHintKey`（survey/vote 勿写「等开奖」）

### 2.3 会话清理

`clearLotteryParticipationSession` 调用 `clearJoinedHints`，避免换号后仍显示已参与。

### 2.4 i18n

补 `statusHintJoinedNoResult` / `Vote` / `Ordered` / `Instant`（中/英）。
