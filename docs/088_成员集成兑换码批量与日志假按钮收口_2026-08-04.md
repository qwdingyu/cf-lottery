## 改动

| 页面 / API | 能力 |
| --- | --- |
| AdminMembersView | 多选（非 owner）+ 批量移除；单条也改 ConfirmDialog |
| AdminIntegrationsView | Webhook / API Key 双 Tab 多选 + 批量删除；去掉 `window.confirm` |
| AdminRedemptionCodesView | 仅 active 可勾选；单条/批量禁用 |

## 安全默认

- 成员：`canRemoveMember` 排除 owner。
- 兑换码：只禁不删，保留 `redemption_records` / 审计追溯。
- 日志：不开放租户侧 bulk delete，避免空壳按钮。

## 辅助函数

- `canRemoveMember(role)`
- `canDisableRedemptionCode(status)`
