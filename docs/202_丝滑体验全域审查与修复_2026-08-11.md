## 二、核心资金/数据安全结论

### 秒杀（Flash Sale）—— 无超发、无漏发

| 路径 | 防护 | 结论 |
|:-----|:-----|:----:|
| 名额抢占 | activeParticipantCount < effectiveMax CAS | 不超卖 |
| 并发下单 | entry.paymentStatus='' CAS 乐观锁 | 仅一单 |
| 回调幂等 | 事务内重读状态 + 三重防护 | 不多发卡 |
| 卡密领取 | 子查询选最小ID + 条件 UPDATE + RETURNING | 原子取卡 |
| 卡密不足 | 全量失败回滚，FULFILLMENT_FAILED | 可补发 |
| 迟到回调 | 标记 paid_late_needs_refund，不入库 | 不污染 |
| 超时释放 | 同事务释放订单+entry+计数器 | 不漏名额 |

### 抽奖（Lottery）—— 无超发、无漏发

| 路径 | 防护 | 结论 |
|:-----|:-----|:----:|
| 延迟开奖 | CAS 夺取 open→drawing + 治愈机制 | 不双开奖 |
| 即时抽奖 | spinsLeft>=1 CAS + awardedCount<winnerCount CAS | 不超发 |
| 幂等回放 | idempotencyKey UNIQUE + 回放不重复占码 | 不重发 |
| 跨租户隔离 | 所有查询带 tenantId | A 不消耗 B |

## 三、丝滑体验发现与修复

### 1. 支付弹窗关闭确认（已修复）

**问题**：用户正在支付中，误点关闭按钮或遮罩层关闭支付弹窗，轮询被清除。
**修复**：pending 状态时弹出确认对话框，防止误关闭。

### 2. 支付关闭后恢复入口（已修复）

**问题**：用户关闭支付弹窗后，sessionStorage 被清除则只能通过 OTP 找回。
**修复**：已参与直付秒杀的状态条增加找回支付订单按钮，点击弹出邮箱+OTP。

### 3. 支付轮询超时机制（已修复）

**问题**：startPaymentPolling 每 3.5 秒无限轮询。
**修复**：增加 5 分钟超时停止轮询；visibilitychange 暂停轮询。

### 4. 秒杀开始倒计时（已修复）

**问题**：活动未开始时用户看不到还有多久开始。
**修复**：增加实时倒计时显示，倒计时到 0 自动刷新状态。

### 5. 批量购买 +/- 按钮（已修复）

**问题**：maxPerUser > 1 时只有原生 input，移动端体验不佳。
**修复**：增加 -/+ 按钮。

### 6. 二维码加载状态（已修复）

**问题**：QR 区域没有加载指示器。
**修复**：显示正在生成支付二维码文字。

### 7. 支付成功 Toast（已修复）

**问题**：轮询检测到 paid 后没有 toast 通知。
**修复**：状态从 pending 变为 paid 时弹 toast。
