## 0. 核心原则（必须遵守）

1. **SSH 必须使用私钥**：`~/.ssh/jp_72_scp-key`，禁止密码登录
2. **本地编译，远端只部署产物**：不在 VPS 上 git pull / npm install 源码
3. **部署包是 tar.gz**：`dist/server.js` + `public/` + `package.json` + `migrations/`
4. **不支持 ecosystem.config.json**：2026-08-08 已从仓库和 VPS 删除，全面使用 systemd
5. **数据库迁移自动执行**：server.js 启动时自动 applyPendingMigrations，禁止手动 npm run db:migrate
6. **VPS npm install 可能断开**：SSH 不稳定时用 `nohup bash -c "npm install --omit=dev && systemctl restart cf-lottery" > /tmp/deploy.log 2>&1 &`

## 2. 部署流程

### 2.1 步骤一：构建 + 上传（本地执行）

```bash
cd /Users/dingyuwang/0-X/github_workflow/templates/cf-lottery

# 一键构建 + 上传
VPS_SSH_KEY=~/.ssh/jp_72_scp-key bash local-deploy-vps.sh
```

`local-deploy-vps.sh` 自动完成：
1. 迁移文件唯一性检查
2. `npx tsc --noEmit` 类型检查
3. `cd frontend && npx vue-tsc -b --pretty false` 模板检查
4. `npm --workspace frontend run build` 前端构建 → `public/`
5. `npx esbuild src/server.ts ...` 后端打包 → `dist/server.js`
6. `tar -czf cf-lottery-deploy-YYYYMMDD-HHMMSS.tar.gz` 打包
7. `cat | ssh cat` 上传到 VPS `/root/`

### 2.2 步骤二：VPS 部署（SSH 执行）

```bash
ssh -i ~/.ssh/jp_72_scp-key -o ServerAliveInterval=5 root@38.47.198.72

# 1. 进入运行目录
cd /root/cf-lottery

# 2. 解压新版本
tar -xzf /root/cf-lottery-deploy-*.tar.gz

# 3. 安装/更新运行时依赖（仅生产依赖）
npm install --omit=dev

# 4. 重启服务（启动时自动执行数据库迁移）
systemctl restart cf-lottery

# 5. 检查启动状态
systemctl status cf-lottery
# 期望：Active: active (running)

journalctl -u cf-lottery -n 5 --no-pager
# 期望最后几行：
#   [migrate] 数据库 schema 已是最新（本地 SQLite）
#   [server] cf-lottery on http://localhost:8787
#   [server] platform: local
```

> ⚠️ 若 SSH 在 `npm install` 期间断开（VPS 内存不足导致），改用：
> ```bash
> nohup bash -c "cd /root/cf-lottery && npm install --omit=dev && systemctl restart cf-lottery" > /tmp/deploy.log 2>&1 &
> # 等待 15 秒后 ssh 回去查看 cat /tmp/deploy.log
> ```

### 2.3 步骤三：验证

## 4. 环境变量

VPS 上 `.env` 文件位于 `/root/cf-lottery/.env`，通过 systemd `EnvironmentFile` 加载。

关键变量（**禁止写入仓库**）：

| 变量 | 说明 | 示例 |
|------|------|------|
| `TURSO_URL` | 数据库连接 | `file:./data/data.db` |
| `TURSO_TOKEN` | 数据库令牌 | 留空（本地 SQLite 无需） |
| `JWT_SECRET` | JWT 签名密钥 | （生产密钥） |
| `CF_AUTH_ISSUER` | cf-auth 网关地址 | `https://auth.eforge.xyz` |
| `CF_AUTH_CLIENT_ID` | cf-auth 客户端 ID | （OAuth 凭证） |
| `CF_AUTH_CLIENT_SECRET` | cf-auth 客户端密钥 | （OAuth 凭证） |
| `APP_ORIGIN` | 应用根域名 | `https://lucky.eforge.xyz` |

## 7. 故障排查

| 症状 | 检查方法 | 常见原因 |
|------|----------|----------|
| Nginx 502 | `systemctl status cf-lottery` | Node 进程崩溃或未启动 |
| 站点返回 500 | `journalctl -u cf-lottery -n 50` | 数据库迁移失败 / .env 配置缺失 |
| `npm ci` 报错 | 检查 lock 文件是否匹配 | 跨环境 lock 冲突，改用 `npm install --omit=dev` |
| SSH 频繁断开 | `-o ServerAliveInterval=5` | VPS 内存不足（`free -h` 查看），改用 nohup |
| 端口冲突 | `ss -tlnp \| grep 8787` | 残留进程，`fuser -k 8787/tcp` 后重启 |
| 磁盘满 | `df -h` | 清理旧部署包 `rm /root/cf-lottery-deploy-*.tar.gz` |
