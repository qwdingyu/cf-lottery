## 二、安全面（证据级）

### 本轮已修

| 项 | 风险 | 处置 |
|----|------|------|
| 未知 `/api/*` 回落 SPA HTML 200 | 客户端当 JSON 解析失败；掩盖路由是否存在 | `src/index.ts`：`app.all("/api/*", 404 JSON)` + SPA 双保险；单测 `api-unknown-route.test.ts` |
| **CRITICAL** 注册 `/verify-email` 可误用活动 OTP | 活动码完成账号验证+JWT | 强制 `drawId=""`；优先绑定未验证用户；单测防混用 |
| **HIGH** Node 下 `CF-Connecting-IP` 可伪造 | 打穿 IP 限流 | Node 默认不信；需 `TRUST_CF_CONNECTING_IP` / `TRUST_PROXY_HEADERS` 或 Workers 运行时 |
| **HIGH** 禁用用户/暂停租户后 JWT 仍可用 | 最长至 token 过期 | `requireAuth` 查 `users.status`；`requireTenantMember` 查 `tenants.status` |
| **HIGH** exchange 任意 `redirectUri` | 扩大授权码兑换面 | 仅允许配置值；忽略/拒绝客户端不一致 URI |
| exchange 错误回传 IdP detail | 侦察面 | 路由不再下发 `detail` |
| 密码/访问密码/注册 OTP hash 明文 `===` | 计时侧信道理论面 | `src/lib/crypto-compare.ts` + `auth` / `verifyAccessPassword` 常量时间比较 |
| 缺基线安全响应头 | MIME 嗅探 / referrer 泄漏 | `nosniff`、`Referrer-Policy`、`Permissions-Policy`、`X-DNS-Prefetch-Control`（**不**设 Frame DENY，保留嵌入） |

### 仍存在 / 需知情（非本轮灾难）

| 级别 | 项 | 说明 | 建议 |
|------|-----|------|------|
| **中** | CORS `origin: *` | 公共嵌入需要；管理写靠 Bearer JWT，**非** cookie 会话 | 保持；勿对 Bearer 误开 credentials |
| **中** | `enable_email_verification=false` | open 可无 OTP 直参（配置开关） | 生产默认 true；改关需审计 |
| **中** | JWT 存 localStorage | XSS 可窃 token；当前无用户可控 `v-html` | 禁止 v-html 用户 HTML；中期 CSP |
| **低** | 业务 logout 无服务端黑名单 | 靠短 TTL | 可接受 |
| **低** | 无 IdP 全局登出 | RP 与 auth 无共享 BA cookie | 产品可选 |
| **低** | 遗留 LOGTO_* secrets | 代码应无引用 | 运维可删 |
| **低** | CF_AUTH vars/secrets 重复 | deploy 警告 | 删重复 secret |
| **低** | 密码为 HMAC-SHA256+pepper | 非 Argon2；Worker CPU 约束下的已知权衡 | 文档已说明；中期可升级 |
| **观察** | create-client 任意登录用户（IdP） | cf-auth 平台债 | 白名单 |
| **观察** | 内存 rateLimitMap（auth 部分） | 多 isolate 不共享 | 已有 DB 限流补强关键路径 |

### 已相对扎实（保持）

- cf-auth：PKCE S256、secret 不下发 meta、假 code → IdP invalid_grant  
- 模拟登录：仅 `impersonated=true` JWT 写独立 key  
- 登录/注册/exchange/公开参与：有限流  
- Cron HTTP：需 `CRON_SECRET` Bearer  
- 公开活动用 `public_slug`，不暴露内部 ID  
- 管理写接口 `tenantId` 来自 JWT 中间件，ORM 查询带租户条件  
- 无用户内容 `v-html`（仓库 grep 为空）  
- 开奖 CSPRNG 部分 Fisher-Yates；访问密码 salt 哈希
