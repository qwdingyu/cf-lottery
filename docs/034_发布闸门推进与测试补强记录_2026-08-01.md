## 二、关键修正说明

### 2.1 注册关闭不能刷限流表

关闭公开注册用于 MVP 内测或邀请制。注册关闭时继续写 `rate_limit_log` 没有业务价值，反而会消耗 Turso rows written 和存储。因此注册开关检查前移到 DB 级限流之前。

保留内存限流在最前面，因为它不落库，可拦截短时间内的恶意请求。

### 2.2 Webhook 配额的 0 不是无限

`maxActivities` 中 0 表示不限，是历史配置语义；但 `free_plan_max_webhooks` 的 0 应表示 Free 套餐不能创建 Webhook。把 0 当作 null 会绕过套餐限制，造成外部投递成本失控。

### 2.3 媒体路由测试边界

媒体测试只锁住 P1 必须边界，不引入媒体库、大图处理、在线裁剪或用户侧上传：

```text
后台 owner/admin 才能上传
viewer 不能上传
未绑定 R2 返回明确 503
文件签名和 MIME 必须一致
公开读取只允许 managed images key
公开响应带 nosniff 和长缓存
```
