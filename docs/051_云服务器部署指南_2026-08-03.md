# 云服务器部署指南（Debian + Node.js + SQLite）

日期：2026-08-03
适用：Debian 11/12（bullseye/bookworm）
数据库：本地 SQLite（`file:./data/local.db`）

## 一、架构

```
用户 → Cloudflare DNS → 服务器 IP
                          ↓
                    nginx (443 SSL)
                          ↓
              Node.js Hono Server (:8787)
                          ↓
              SQLite (data/local.db)
```

## 二、准备工作

1. **购买云服务器**（推荐 1C2G，Debian 12）
2. **获取服务器 IP**
3. **Cloudflare DNS 配置**：
   - 登录 Cloudflare → lucky.eforge.xyz → DNS → 记录
   - 删除现有的 A 记录（如果有）
   - 添加 A 记录：`名称 @` → `IPv4 地址 <服务器IP>` → 代理关（灰色云）
   - TTL 60 秒（快速生效）

## 三、一键部署

```bash
# 1. SSH 登录服务器
ssh root@<服务器IP>

# 2. 克隆项目
git clone https://github.com/qwdingyu/cf-lottery.git /opt/cf-lottery

# 3. 执行部署脚本
cd /opt/cf-lottery
bash scripts/setup-cloud-server.sh

# 4. 编辑 .env 中的 JWT_SECRET（修改为随机字符串）
nano /opt/cf-lottery/.env
```

## 四、数据迁移（从 Turso）

```bash
cd /opt/cf-lottery
npm run db:export    # 导出 Turso → data/local.db
```

## 五、SSL 证书

```bash
certbot --nginx -d lucky.eforge.xyz
# 跟随提示操作，证书自动续期
```

## 六、代码更新

```bash
cd /opt/cf-lottery
bash scripts/update-cloud-server.sh
```

## 七、服务管理

```bash
systemctl status cf-lottery   # 查看状态
systemctl restart cf-lottery  # 重启
journalctl -u cf-lottery -f   # 查看日志
```

## 八、验证

```bash
curl http://localhost:8787/api/health
# → {"ok":true,"db":true}

curl https://lucky.eforge.xyz/api/health
# → 同上（通过 nginx）
```

## 文件清单

| 文件 | 作用 |
|------|------|
| `scripts/setup-cloud-server.sh` | 一键部署脚本 |
| `scripts/update-cloud-server.sh` | 代码更新脚本 |
| `scripts/cf-lottery.service` | systemd 服务定义 |
| `scripts/nginx-lucky.eforge.xyz.conf` | nginx 反向代理配置 |
| `src/server.ts` | Node.js 入口 |
| `scripts/export-turso-to-local.mjs` | Turso 数据导出 |
| `.env` | 环境变量（TURSO_URL=file:./data/local.db） |

## 安全建议

1. 修改 `JWT_SECRET` 为随机 64 字符
2. 配置防火墙：`ufw allow 22,80,443/tcp`
3. nginx 中限制 API 频率（可选）
4. 定期备份 `data/local.db`
