## 不变量（验收）

1. **同一用户** = 同一 entry；`maxSpinsPerEntry` = **抽奖次数**硬顶，**不是**中奖次数封顶。  
2. **join 默认发 1 次**（`initialSpinsOnJoin=1`），且 ≤ maxSpins。  
3. **裂变 actual** = min(每邀加次, maxSpins−granted, maxExtra−viralEarned)；榜 +1 与加次解耦。  
4. **instant 禁止** performDraw / Cron 扫到 / 管理端「立即开奖」。  
5. **前端时序**：先 spin 成功 → 再 celebrate + 对准 `prizeIndex`；无索引不宣称中奖。  
6. **winners UNIQUE** = `(tenant, draw, spin_id)`；delayed 用 winner 自身 id 占位。
