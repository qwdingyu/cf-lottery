## 零、架构设计：可插拔游戏引擎

### 0.1 核心思想

**每种参与模式对应一种游戏交互，游戏组件通过统一接口插拔。**

```
LotteryView（抽奖页）
├── GameRegistry（游戏注册表）
│   ├── WheelGame  ← 大转盘（open 模式）
│   ├── SlotGame   ← 老虎机（invite_code 模式）
│   ├── ScratchGame ← 刮刮卡（password 模式）
│   └── CardGame   ← 卡片翻转（roster 模式）
└── GameResultModal（统一结果弹窗）
```

### 0.2 游戏组件接口

```typescript
interface LotteryGameProps {
  prizes: PrizeItem[]       // 奖品列表
  disabled: boolean         // 是否禁用
  mode: string              // 参与模式
  draw: LotteryDraw         // 活动信息
}

interface LotteryGameEmits {
  play: []                  // 用户触发游戏
  result: [winner: boolean] // 游戏结果
}
```

### 0.3 模式到游戏的映射

```typescript
const GAME_MAP: Record<string, string> = {
  'open':       'WheelGame',      // 公开 → 大转盘
  'invite_code': 'SlotGame',      // 邀请码 → 老虎机
  'password':   'ScratchGame',    // 密码 → 刮刮卡
  'roster':     'CardGame',       // 名单 → 卡片翻转
}
```

### 0.4 新增游戏的步骤

1. 创建 `src/components/games/NewGame.vue`，实现 `LotteryGameProps` 接口
2. 在 `GameRegistry` 中注册映射关系
3. 无需修改 `LotteryView` 或其他代码

## 一、现有抽奖程序分析

### 1.1 五个程序的 UI 模式

| 程序 | 模式 | 视觉效果 | 可借鉴点 |
|------|------|---------|---------|
| lucky_wheel | 大转盘 | 旋转指针 + 扇形奖品 + 弹窗中奖 | 转盘动画、奖品图标、每日次数 |
| lottery tiger | 老虎机 | 三列滚动 + 逐列停止 | 逐列停止的悬念感、缓动动画 |
| turntable | 转盘 | 旋转转盘 + 指针 | 转盘样式 |
| 2 | 九宫格 | 方格闪烁 | 快速高亮切换 |
| cloud189 | 刮刮卡 | 刮开涂层 | 互动感强 |

### 1.2 关键设计元素

| 元素 | 作用 | 实现难度 |
|------|------|:--:|
| 转盘动画 | 制造悬念和期待感 | 中 |
| 逐列停止（老虎机） | 逐列揭晓，层层递进 | 中 |
| 中奖弹窗 | 明确告知结果，引导下一步 | 低 |
| 倒计时/次数 | 制造稀缺感，促进回访 | 低 |
| 音效 | 增强沉浸感 | 低 |
| 奖品图标 | 视觉化奖品价值 | 低 |
| 未中奖安慰 | 优惠券/小礼品，降低挫败感 | 低 |

## 二、cf-lottery 前端体验升级方案

### 2.1 四种参与模式 → 四种交互体验

| 参与模式 | 推荐交互 | 说明 |
|---------|---------|------|
| 公开抽奖 | 大转盘 | 最直观，适合公开活动 |
| 名单抽奖 | 卡片翻转 | 适合企业年会，正式感 |
| 密码进入 | 刮刮卡 | 输入密码后"刮开"结果 |
| 邀请码 | 老虎机 | 输入邀请码后"拉杆" |

### 2.2 大转盘模式（公开抽奖，P0）

**设计**：借鉴 lucky_wheel 的转盘设计。

```
┌──────────────────────────────────────┐
│          🎯 2026 年会抽奖            │
│                                      │
│         ┌──────────────┐             │
│         │   ╱‾‾‾‾‾╲   │             │
│         │  ╱ 奖品A ╲  │             │
│         │ │  奖品B  │ │             │
│         │ │  奖品C  │ │   ← 旋转    │
│         │  ╲ 奖品D ╱  │             │
│         │   ╲______╱   │             │
│         │      ▼       │   ← 指针    │
│         └──────────────┘             │
│                                      │
│      📧 user@email.com               │
│      [🎰 参与抽奖]                    │
```

## 三、导流闭环设计

### 3.1 中奖后的导流路径

```
中奖弹窗
├── 卡密奖品 → 展示卡密 + 复制按钮
├── 虚拟奖品 → 展示兑奖说明
├── 商品链接 → [🛒 立即购买] 按钮
└── 未中奖 → 优惠券码 + [🛍️ 去逛逛] 按钮
```

### 3.2 未中奖安慰

```
未中奖弹窗
├── 安慰语：「差一点就中了！送你一张优惠券」
├── 优惠券码：LUCKY2026（满100减20）
├── [复制优惠券] [🛍️ 去逛逛]
└── 底部：「明天再来试试手气」
```

### 3.3 分享裂变

```
中奖后
├── [📤 分享到微信]
├── [📋 复制活动链接]
├── [🔗 生成我的邀请码]
└── 分享文案：「我中奖了！你也来试试手气吧！」
```
