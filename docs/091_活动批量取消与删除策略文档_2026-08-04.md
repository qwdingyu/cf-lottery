## 1. 批量取消

| 项 | 说明 |
| --- | --- |
| 范围 | 仅 `draft` / `open` / `paused` → `POST .../cancel` |
| 不可取消 | `drawn` / `drawing`（与 `cancelDraw` 一致） |
| UI | bulk-bar「取消选中」+ 摘要「可取消 N」 |
| 相对删除 | 终态保留行，适合关停测试活动；物理删仍走既有批量删除 |

辅助：`canCancelDraw(status)`；`canSelectDrawForBulk` 含可取消。

## 2. 删除策略（与后端同源）

实现：`describeDrawDeletePolicy()`（`ops-utils`，单测覆盖）。

| 状态 | 默认可删 | 说明 |
| --- | --- | --- |
| draft | 是 | 草稿清场 |
| paused | 是 | 已停收可删 |
| drawn | 是 | 删级联 winners/entries 等；订单/卡密交付保留 |
| cancelled | 是 | 终态可物理清 |
| open | **否** | 须先 pause 或 cancel |
| drawing | **否** | 开奖中不可删、不可取消 |

**不默认 force**：不提供一键删 open/drawing；不引入服务端 batch-delete force 档（仍属 P2 大数据量场景）。

后端证据：`DELETE /api/admin/draws/:id` 对 `open`/`drawing` 返回 400。
