# 秒杀批量购买阶梯价前端UX修复记录

## 背景

前端公开页已经具备秒杀直付、批量购买和阶梯定价能力，但卡片展示只显示固定单价，数量输入也缺少显式整数提示，容易让用户误判最终应付金额。

## 问题

1. 直付秒杀商品卡只展示固定单价，不显示当前件数对应的阶梯总价。
2. 购买件数输入仅靠浏览器默认约束，缺少明确的正整数提示。
3. 阶梯价虽然在后端可计算，但前端未把“当前档位”显式展示出来。

## 处理

1. 新增前端纯函数 `buildFlashSalePurchaseSummary()`，按当前件数计算单价、总价和生效档位。
2. 在 `LotteryView.vue` 的秒杀商品卡中补充：
   - 当前单价
   - 当前总价
   - 当前阶梯档位
3. 将数量输入显式改为 `step="1"`，并增加正整数提示。
4. 补充中英文文案和纯函数测试。

## 验证

- `npx tsc --noEmit`
- `npx vitest run`

结果：通过。
