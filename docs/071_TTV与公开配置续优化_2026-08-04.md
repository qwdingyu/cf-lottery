# 071 TTV 与公开配置续优化

> 日期：2026-08-04  
> 承接：docs/055a P1、docs/070 建议后续  
> 原则：轻量、可回滚、不重写 AdminLotteryView

---

## 一、本轮改动

| # | 项 | 说明 |
|---|-----|------|
| 1 | **空奖品库可发布** | `quickCreatePrize` 默认 `manual_fulfillment`（非 code），不自动造码；对齐 publish-check「仅 code 校验库存」 |
| 2 | **创建引导** | 空库提示文案；模板应用后若无奖品库 toast 提示点「快速创建」 |
| 3 | **Demo 次 CTA** | 公开配置 `demo_public_slug`；Landing 有值则链 `/lottery/{slug}`，否则仍 `#how-it-works` |
| 4 | **API Key 列表** | 不再返回 key 哈希；仅 `prefix` 展示字段 |
| 5 | **health** | `dbError` 改为布尔，不回传内部错误字符串 |

---

## 二、运营怎么用 Demo

1. 后台创建并**发布**一条活动，复制公开链接中的 `public_slug`  
2. 平台系统配置 → 写入 `demo_public_slug` = 该 slug  
3. 落地页次按钮变为真实活动深链（仍不指向注册）

未配置时行为与 055a P0 一致：锚到「怎么玩」。
