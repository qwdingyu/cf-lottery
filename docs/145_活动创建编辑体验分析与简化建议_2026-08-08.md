# 145 活动创建/编辑体验分析与简化建议

> 日期:2026-08-08
> 视角:产品经理+UI设计+资深用户+行业顾问

## 现状

编辑器表单 ~742 行,含 50+ 表单字段,分布在4个区域:
基本信息、参与设置、奖品配置、增长配置(含秒杀/支付/裂变/CTA)

**新手认知负荷**:首次创建活动,面对满屏字段不知所措

## 根因(3个)

1. **字段平铺**:所有字段一次展示,缺少"基础/高级"分层
2. **无引导**:没有步骤导航条,用户不知道"填到哪了/还剩多少"
3. **模板后不收敛**:选择模板后,所有高级字段仍全展开

## 整改建议(按优先级)

### P0(30分钟):默认折叠高级区

- 默认只显示"基本信息+时间"
- "参与模式"折叠,"奖品配置"只在有奖品时展开
- "增长配置"折叠(提示"可选:秒杀/支付/裂变")
- 保存当前状态到 sessionStorage,避免关闭后丢失

### P1(1天):加步骤导航条

- 4步:基础→参与→奖品→营销
- 每个步骤独立校验(填完才能下一步)
- 顶部进度条显示当前进度
- 参考:Shopify 产品创建、WooCommerce 产品向导

### P2(2天):模板创建后只显示差异字段

- 选择"限时抢购"模板后,自动展示价格/库存/支付字段
- 选择"免费大转盘"后,不显示支付相关字段
- 减少无效配置暴露

### 不改(保持现有)

- 不做"极简模式"(会丢失已有功能)
- 不把所有字段隐藏到弹窗(现有表单布局已可用)

## 参考

- Shopify:"Title → Description → Media → Pricing → Inventory → Variants"分步展示
- cf-shop AdminProductsView:相同复杂度但通过弹窗+折叠管理
