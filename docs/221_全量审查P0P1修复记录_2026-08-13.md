## 一、后端核心批（commit 20c4625，已提交）

### P0-1 排行榜奖励多码重复发放（资损）→ 已修复
- 根因：`grantLeaderboardRewards` 按单条 share_record 行取 TopN 并逐行发放，CAS 幂等键是每行 `leaderboardRewardedAt`；rankMap 按 sharer 去重后，同一分享者多条码会**各自命中同名次、各发一次奖励**（超发）。且排名口径（单行 joinedCount）与公开榜 SUM 口径不一致。
- 修复（src/services/lottery/leaderboard-rewards.ts）：
  1. 先按 `sharerEntryId` 聚合全部 share_record（SUM joinedCount，joined=0 不参与），与公开榜 `aggregateViralInviteCounts` 同一口径；
  2. 每个分享者只发放一次；幂等标记写入该分享者**全部**记录（任一行为空即未发放，CAS rowsAffected===记录数）；
  3. 同票按该分享者最早分享时间（created_at 升序，先到先得）；
  4. 发放受 `maxSpinsPerEntry` 总顶裁剪（granted ≤ maxSpins 不变量），裁剪时 refId 追加 `:capped` 供对账；
  5. 契约对齐：`viral.enabled !== true` 或 `leaderboardEnabled === false` 时不发放（缺省视为开启，与 `isViralLeaderboardEnabled` / publish-check 一致）。
- 测试：spin-execution.test.ts 新增多码只发一次 / leaderboardEnabled 缺省 / viral.enabled=false / maxSpins 裁剪 4 用例；既有 6 用例全部保持通过。

  2. `importPrizeCodes` 导入前显式查重（同租户同奖品已存在 + 批次内重复 + 空码），返回 `{ imported, skipped }`；
  3. 导入路由回报 skipped 数，运营可见；

- 测试：批次内重复去重 / 库中已存在跳过 / 唯一约束硬兜底 / 跨租户同码不冲突 4 用例。
- 注意：存量重复码中被 revoke 的那张卡的持有者需运营线下补偿（保留 winner/order 关联可追溯）。

### P1-1 每日免费计入 spinsTotalGranted 毒化裂变/里程碑预算 → 已修复
- 根因：`spin-execution.ts` 每日免费领取 `spinsTotalGranted += count`（无 maxSpins 上限），`granted` 被推高后裂变/里程碑的 `roomTotal = max - granted` 恒为 0，邀请奖励被永久锁死；与签到"刻意不更新 granted"（spin-execution.ts:588-592 注释）直接矛盾。
- 修复：每日免费只加 `spinsLeft`（与签到同语义），不再更新 `spinsTotalGranted`。
- 影响：`spinsUsed = granted - left` 低估免费次数（与签到一致，docs/171 §11.4.2 已接受，无用户感知）。
- 测试：更新 2 处旧断言（granted 不再含每日免费）；集成链路测试保持通过。

### P1-3 里程碑按单条 shareRecord 计数 → 已修复
- 根因：`processReferralMilestoneRewards` 只读触发记录的 `joinedCount`，多码分享者（SUM 口径达标）永远无法触发里程碑。
- 修复（participation.ts）：按分享者聚合全部记录 SUM(joinedCount)；幂等键升级为分享者维度（已发放集合 = 全部记录 `rewardMilestonesGranted` 并集，发放后写入全部记录）。

### P1-4 里程碑被裁剪后仍标记已发放（承诺奖励静默损失）→ 已修复
- 根因：`actual = min(bonus, room)` 裁剪后仍把全部 due 门槛写入 `rewardMilestonesGranted`。
- 修复：只发放并标记**能足额覆盖**的里程碑（requireCount 升序贪心）；首个放不下的门槛及之后全部保留为 deferred（不发放、不标记，后续 join 重新评估），`spins_log.refId` 追加 `:deferred:{门槛列表}` 供运营对账。
- 测试：多码聚合触发 / 预算不足不发放不标记 2 用例。

### P1-2 排行榜发放侧 leaderboardEnabled 契约反转 → 已修复
