# 平台层出站闭包与QQ群助手管理端实现（167 Phase 1 闭环）

## 背景

docs/167 定义了"嫁接层"架构：平台抽象层（Platform Adapter / Inbound / Outbound）将 NapCat/OneBot 等第三方 QQ 机器人能力封装为统一接口，业务层只依赖平台抽象，不感知底层实现。

此前入站方向（QQ 群消息→cf-lottery 业务）已完整实现（createQQAdapter、BuiltinCommandRouter、POST /api/platform/qq/message、签到/分享命令、鉴权、13 例测试），但出站方向（cf-lottery 事件→QQ 群消息）和管理端配置（platformTargets CRUD）完全缺失。

本次实现完成 Phase 1 的剩余闭环项。

## 实现内容

### 1. 平台目标管理端 CRUD API（admin-lottery-platform.ts）

新增 `src/routes/admin-lottery-platform.ts`，挂载到 `adminLotteryRoute`（`/admin` 命名空间下）：

- `GET /platform-targets` — 列表（分页）
- `GET /platform-targets/:id` — 详情
- `POST /platform-targets` — 创建（自动生成入站密钥，校验活动归属，防重复群号）
- `PUT /platform-targets/:id` — 更新（名称/活动/命令开关/配置）
- `DELETE /platform-targets/:id` — 删除
- `POST /platform-targets/:id/reset-secret` — 重置入站密钥

设计约束：
- 创建时返回 `inboundSecret`（`pin_` 前缀 UUID），明文只返回一次，库中只存 SHA-256 哈希
- token 等敏感字段创建时以 `[encrypted]` 占位符落库，避免明文存储
- 所有写操作记录 `auditLogs` 审计

### 2. 平台消息模板系统（templates.ts）

新增 `src/services/platform/templates.ts`：

- `renderPlatformTextTemplate()` — 纯文本替换（无 HTML 转义），与 `interpolate` 差异：不做 `escapeHtml`
- 支持 `{{#if}}` 条件块和 `{{变量}}` 替换
- 9 种事件模板：draw.published/completed、entry.created、outcome.assigned、prize.issued、reward.earned、penalty.requested、share.created、checkin.completed

### 3. 出站投递服务（delivery.ts）

新增 `src/services/platform/delivery.ts`：

- `enqueuePlatformEvent(db, input)` — 查匹配的 platformTargets（tenant + activeDrawId + assistantEnabled），渲染模板，写入 platformDeliveries
- `dispatchPlatformDeliveries(db, limit)` — 拾取 pending 投递，经 QQ 适配器发送，3 次重试 + 指数退避
- `processPendingPlatformDeliveriesForAllTenants()` — 维护 cron 入口

### 4. 业务热路径集成

- `draw-execution.ts` — 开奖完成时入队 `draw.completed` 平台消息
- `reward.ts` — 奖励触发时入队 `reward.earned` 平台消息
- `integration.ts` — 退群处罚时入队 `penalty.requested` 平台消息
- `index.ts` — 维护 cron 增加平台消息投递分发

### 5. 管理端 QQ 群助手页面（AdminQqAssistantView）

新增 `frontend/src/views/admin/AdminQqAssistantView.vue`：

- 群绑定列表（群名称、群号、绑定活动、启用状态）
- 创建弹窗：输入群号、选择活动、适配器配置、内置命令开关
- 编辑弹窗：修改名称、活动、命令开关
- 删除/启停/重置密钥操作
- 入站密钥明文高亮展示（仅创建/重置时出现，用户可一键复制）
- 路由 `/admin/qq-assistant` + 侧边栏菜单

## 架构图

```
管理员操作平台
  → admin-lottery-platform.ts (CRUD platformTargets)
  → platformTargets 表（存储绑定关系）

业务事件（draw.completed / reward.earned / penalty.requested）
  → enqueuePlatformEvent() → platformDeliveries 表（pending）
  → dispatchPlatformDeliveries() → createQQAdapter.send() → QQ 群消息
  → platformDeliveries 表（sent/failed）
```
