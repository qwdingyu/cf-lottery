# 095 公开参与游戏反馈与文案细化

日期：2026-08-04  
触发：继续审查「用户丝滑度 / 大转盘等视觉 / 核心功能」后的高 ROI 打磨。

## 1. 审查发现（细节）

| 问题 | 影响 | 处理 |
| --- | --- | --- |
| Slot 仅文案「提交中」，滚轮完全静止 | 比 Wheel 钝，像点了没反应 | loading idle 三轴轻晃 + 按钮脉冲 |
| 底部 `gamePrimaryCtaHint` 通吃「点转盘」 | 老虎机/刮刮卡文案错位 | 按 experience 细分 i18n key |
| 奖池 `aria-label="prizes"` 硬编码英文 | a11y / 中文页不友好 | `prizeStripAria` 中英 |
| Wheel/Slot 无 `prefers-reduced-motion` | 持续 rAF 对敏感用户不友好 | 减少动态时跳过 idle |
| Grid 点格后无选中高亮 | 提交中不知道点的哪一格 | loading 高亮 pending 格 |
| Card/Scratch 提交按钮无脉冲 | loading 态像灰掉死按钮 | loading 类 + 脉冲 |
| OTP 发码/验码邮箱未 toLowerCase | 与后端/JWT 路径不一致 | handleSendCode / handleVerifyCode 规范化 |
| types 注释写「loading 不要驱动动画」 | 与 093 idle 策略冲突 | 改为允许轻量 idle，禁止假开奖长动画 |

## 2. 本波改动

- `SlotGame` / `WheelGame` / `GridGame` / `CardGame` / `ScratchGame` 提交反馈对齐  
- `gamePrimaryCtaHintKey` + 中英 i18n  
- `public-helpers.test.ts` 回归  
- 仍**不**做：停扇对齐真实中奖、音效、假 Demo 中奖
