# 058 大文件模块级拆分

**日期**：2026-08-03  
**范围**：前端管理端/公开页抽奖 View、后端 `admin-lottery` 路由

## 背景

`AdminLotteryView.vue`（~3600 行）、`LotteryView.vue`（~2500 行）、`admin-lottery.ts`（~2100 行）难 diff、易误伤。要求**按模块拆、不要拆太碎**（避免十几个 50 行碎片文件）。

## 原则

1. **先抽纯 TS**（类型 / API / 默认值 / 工具），父组件保留编排与大块模板。
2. **后端按域挂载**：延续 `setupPrizeRoutes` 模式，不拆成「每个 endpoint 一个文件」。
3. **共享默认值单点**：`defaultExperience*` / `defaultResultMode*` 前后台对齐，防漂移。

## 变更结果（行数约）

| 文件 | 前 | 后 |
|------|----|----|
| `AdminLotteryView.vue` | ~3623 | ~2889（+ page CSS / lottery/*） |
| `LotteryView.vue` | ~2464 | ~2345（+ lottery/*） |
| `admin-lottery.ts` | ~2119 | ~1236（+ helpers / tenant-ops / integrations） |

### 前端新增

- `frontend/src/lib/activity-defaults.ts` — 三维默认体验/结果模式（Admin + 公开页共用）
- `frontend/src/views/admin/lottery/` — `types` / `api` / `activity-config` / `form-defaults` / `ops-utils` / `admin-lottery-page.css`
- `frontend/src/views/lottery/` — `types` / `public-helpers`（归一化、氛围时长、CTA 协议白名单）

### 后端新增

- `src/routes/admin-lottery-helpers.ts` — 分页、审计、身份展示、CSV/URL 校验、coerce 等
- `src/routes/admin-lottery-tenant-ops.ts` — 审计日志 / 黑名单 / 成员 / 用量
- `src/routes/admin-lottery-integrations.ts` — API Key / Webhook / 券 / 品牌 / 核销

主文件保留：**活动 CRUD、发布开奖、中奖/导出、接龙名单** 等主闭环。

## 未做（刻意）

- 未把创建表单 / 列表再拆成多个 Vue 子组件（模板耦合深，拆太碎收益低）。
- 未动 `public-lottery.ts`（~1165，可下一轮按同样粒度）。
- `LotteryView` 样式仍留在 SFC（`scoped` + `@import` 会丢作用域）。

## 验证

- `npm run type-check`：通过
- `npm run type-check:frontend`：通过
- `npx vitest run`：核心套件通过；`security-audit-verification` 中 register 500 为既有环境问题（`PASSWORD_PEPPER`），与本次拆分无关

## 建议

- 再改管理端抽奖时：业务逻辑优先落 `admin/lottery/*`，View 只接线。
- 新增租户后台「非活动」接口：挂 `tenant-ops` 或 `integrations`，勿再塞回主文件。
