## 一、发版前必须对齐的 Git 状态

```bash
git status -sb
git log --oneline origin/main..HEAD | head -20
git log --oneline HEAD..origin/main | head -5
```

### 1.1 behind 1 的处理（必做）

本地领先且落后 remote 1 时：

```bash
# 先看清 remote 多出的提交，禁止盲 rebase/force
git fetch origin
git log --oneline HEAD..origin/main
git log -1 --stat origin/main

# 推荐：rebase 到 origin/main（冲突只解业务相关，勿引入脏树）
git rebase origin/main
# 若冲突面过大：git rebase --abort，改用 merge 并人工审查
# git merge origin/main
```

**禁止**：`git push --force` 覆盖 origin/main（除非团队书面授权且仅限无他人依赖的分支）。

### 1.2 脏树隔离（必做）

发版 commit **只** 含：

- 已审过的 instant / 安全 / Runbook 相关文件
- **不含** `frontend/src/components/admin/ConfigField*` 半成品、AdminShell 大改、未验收的 `dist/` 乱删

临时隔离示例（按需）：

```bash
# 查看将要提交的 diff
git diff --cached --stat
git status -sb | grep -E 'AdminShell|ConfigField|dist/' || true
```

## 七、Cron 纵深（本提交锁定）

| 层 | 行为 |
|:---|:-----|
| `processDueDraws` WHERE | `activity_kind=lottery` + `draw_trigger=scheduled` + **`result_mode != 'instant'`** + `draw_at<=now` + `status=open` |
| `performDraw` | `resultMode===instant` → 抛错「请使用 spin」 |
| 管理端 POST draw | instant 拒绝 |
| 单测 | `processDueDraws 排除 resultMode=instant` + `仍处理 scheduled 非 instant` |

误配 `instant + scheduled + drawAt 已过` 时：Cron **processed=0**，活动保持 `open`。
