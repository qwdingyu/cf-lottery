## 改动

| 能力 | 说明 |
| --- | --- |
| 可勾选范围 | `canSelectDrawForBulk` 含 open（可暂停）与 paused（可恢复） |
| 批量暂停 | 仅 `open` → `POST .../pause` 顺序执行 |
| 批量恢复 | 仅 `paused` → `POST .../resume` 顺序执行 |
| 导出已选 | CSV：id / publicSlug / title / status / activityKind / visible / createdAt（无参与者 PII） |
| API 薄封装 | `pauseLotteryDraw` / `resumeLotteryDraw` |

## 安全默认

- 暂停/恢复走既有状态机，不 force 改 drawn/drawing。
- 导出仅元数据，不含邮箱/中奖码。
- bulk-bar 摘要分别展示可暂停/可恢复/可隐藏/可删除计数。
