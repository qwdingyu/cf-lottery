# 197 SaaS 多租户数据隔离安全审查（2026-08-11）

> 审查范围：全部 38 个路由文件 + 核心服务 + 中间件。
> 方法：深度子代理逐文件扫描 tenantId 过滤完整性 + 主代理亲读资金/公开要害。
> 结论：**无高危/中危跨租户路径，整体隔离稳健。修复 2 处防御纵深缺口。**

## 2. 已确认的安全架构（多层防御）

### 2.1 中间件层强制隔离
- `requireAuth` 从 JWT 注入 `tenantId`（auth.ts:53）
- `requireTenantMember` 每次请求校验成员身份 + 租户 active 状态（auth.ts:68-109）
- `adminLotteryRoute.use("*", requireAuth, requireTenantMember(), requireTenantRouteCapability)` 覆盖所有 L2 子路由

### 2.2 L2 管理端全部正确
所有子模块（活动/奖品/卡密/黑名单/成员/审计/集成/平台目标）的列表、详情、**by-id 操作**均带 `eq(table.tenantId, tenantId)`。

### 2.3 服务层强制 tenantId
`getDraw`/`getDrawWinners`/`getEntries`/`getActivityOutcomes`/`publishDraw`/`pauseDraw` 等全部 `and(eq(id), eq(tenantId))`。

### 2.4 公开端点正确隔离
- 按 `publicSlug` 查 draw（**全局唯一约束**）→ 派生 `draw.tenantId`
- 卡密找回（public-access.ts）：winners 按 entryIds + `drawId` 双重过滤
- 裂变排行榜：shareRecords 按 `drawId` + `tenantId` 双条件
- 参与/取消/spin：所有写入绑定 `draw.tenantId`

### 2.5 支付隔离
- 回调路径带 tenantId 参数 + `handlePaymentCallback` 校验 `order.tenantId !== pathTenantId → 403`
- 创建订单校验 `entry.tenantId === draw.tenantId`

### 2.6 L3 平台端（设计如此）
- 跨租户操作显式传 tenantId 路径参数（platform_owner/operator）
- `platform_support` 必须指定 tenantId 否则返回空
- 兑换码为平台级表（无 tenantId 列），L3 专属

## 3. 修复的防御纵深缺口（本轮）

### 3.1 healDrawingState 两处 UPDATE 补 tenantId
- **位置**：`draw-execution.ts:853,867`
- **问题**：状态补全/回滚的 UPDATE 只按 `id + status=drawing`，未带 tenantId（入口有校验但防御纵深不足）
- **修复**：两处均加 `eq(lotteryDraws.tenantId, tenantId)`

### 3.2 getDrawEntriesCount tenantId 改必选
- **位置**：`draws.ts:50`
- **问题**：tenantId 参数可选，未来调用方可能漏传导致跨租户计数
- **修复**：改为必选参数（当前无调用方，未来强制显式传）

## 6. 补充亲读抽查（主代理逐行验证，非子代理结论）

在子代理全路由扫描之上，主代理逐行抽查了以下路径（重点补"用户间隔离"维度）：

### 6.1 L2 管理端 by-id 操作（抽查 4 个文件全部双条件）
- admin-lottery.ts：get/copy/patch/publish/draw 全部 `getDraw(db, id, tenantId)` 或 `and(eq(id), eq(tenantId))`
- admin-lottery-prizes.ts：prize 更新/卡密导入/生成/查询/导出全部带 tenantId
- admin-lottery-tenant-ops.ts：黑名单删除/成员改角色/审计删除全部双条件
- admin-lottery-draw-ops.ts：中奖/提交/名单/邀请码全部 and(eq(tenantId))

### 6.2 用户间隔离（my-result 三条件 + 身份门禁）
- `public-lottery.ts:1187` entry 查询：`and(eq(tenantId, draw.tenantId), eq(drawId, draw.id), eq(identityValue, identityValue))`
- 邮箱身份需 OTP（验证码发到本人邮箱），JWT 身份需 bearer——A 用户无 B 的验证码/JWT，无法查 B 的结果
- **用户 A 看不到用户 B 的结果**（即使同租户同活动）

### 6.3 中奖名单脱敏（result 端点）
- `public-lottery.ts:530`：`winners.map(w => ({ identity: maskIdentity(w.identityValue) }))`
- 仅 `showWinnerList=true` 时返回，且身份 maskIdentity 脱敏——不泄露完整邮箱/ID

### 6.4 公开详情不泄露租户内部信息
- `public-lottery.ts:169` 注释明确：不返回 draw.id / tenant_id / 支付密钥 / 卡密库存明细

### 6.5 spin 公开入口按 slug 派生租户
- `performInstantSpin(db, { slug, ... })` 按 publicSlug 查 draw（全局唯一）→ draw.tenantId 派生，用户无法指定租户
