# 074 上线前 UX 死磕：首访闭环与分享优先

> 日期：2026-08-04  
> 原则：死磕用户路径；低成本；有证据；不拆巨页、不改 API  
> 承接：docs/055a P1、docs/070–073

---

## 一、问题（代码证据）

| 路径断点 | 证据 | 用户感受 |
|----------|------|----------|
| 建完工作空间落到 `/admin` | `OnboardingView` 原 `router.replace('/admin')` | 再看空运营台 → 再点创建，**多一步** |
| 活动列表零活动仅「暂无数据」 | `AdminLotteryView` 空行 `adminNoData` | 不知道下一步 |
| Dashboard 空态无样式 | `.empty-onboard` **未定义** CSS | 空态像裸文字 |
| open 抽奖主按钮是「立即开奖」 | 列表 open+lottery 主 CTA = Draw | 分享才是运营主路径；空池易误点 |
| 参与页分享按钮过小 | `.lottery-share-btn` padding 3px | 移动端难点；无 safe-area |

---

## 二、本轮改动

### 1. Onboarding → 创建活动

- 成功：`setToken` → toast → `/admin/draws?new=true`（`onboardingSuccessPath()`）  
- 文案：按钮「创建工作空间并开始搭活动」+ `nextHint`  
- 输入/主按钮 ≥48px、`focus-visible`

### 2. 活动列表 / 运营台空态

- 零活动：标题 + 说明 + **创建活动** 主按钮  
- Dashboard：补 `.empty-onboard` 样式 + 三步文案 `emptyOnboardSteps`

### 3. 分享优先

- open 抽奖：主按钮 **复制链接**；「立即开奖」降级 ghost，**无参与 `disabled`**（`canEnableDrawNow`）  
- open 非抽奖：复制链接升为 primary  
- 列表 TTV 提示文案同步

### 4. 参与页触控

- 顶栏 sticky + safe-area  
- 分享 / 登录 / 查结果 ≥44px；移动端分享全宽  
- reduced-motion 关骨架动画；投票选项触控加大

### 5. 可测纯函数

- `frontend/src/composables/admin-list-ux.ts` + vitest

---

## 三、刻意不做

- 不重写 `AdminLotteryView` / `LotteryView`  
- 不改 publish / join / 开奖 API  
- 不做 Product Tour 引擎、不做假 Demo 截图冒充

---

## 四、验收

```bash
npx tsc --noEmit
npx vitest run
npm run type-check:frontend
npm run frontend:build
```

人工路径：

1. 新账号注册 → 建工作空间 → **应直接弹出/进入选模板**  
2. 活动列表空 → 大按钮创建  
3. 开启活动后列表主操作是复制链接；0 人参与时开奖按钮灰  
4. 手机宽：活动页分享按钮可点、底栏不被 Home 条挡住
