## 完成项

### H1. audit_logs 表 createdAt 索引
- **文件**：`src/db/schema.ts` + `migrations/0059_audit_logs_created_at_index.sql`
- **改动**：给 audit_logs 表添加 `idx_audit_logs_created` 索引
- **原因**：`runRetentionCleanup` 按 createdAt 批量删除，无索引时全表扫描，审计日志增长后维护任务变慢
- **验证**：`tsc --noEmit` 0 errors

### M1. email-service.ts 提取 createEmailService 工厂
- **文件**：`src/services/email-service.ts`
- **改动**：将 `sendEmail` / `sendAccessCode` 中重复的 EmailService 构造（15 行）提取为私有 `createEmailService` 工厂函数
- **原因**：消除重复，通道优先级（cf-auth 网关 → Resend → CF Email）单一实现，避免两处漂移
- **验证**：`tsc --noEmit` 0 errors

### M3. cleanExpiredSpins NOT IN → NOT EXISTS
- **文件**：`src/services/lottery/spin-execution.ts`
- **改动**：`NOT IN (SELECT ...)` → `NOT EXISTS (SELECT 1 FROM ... WHERE ...)`
- **原因**：大表下 NOT IN 子查询性能差（SQLite 需构建完整结果集再比对），NOT EXISTS 用相关子查询短路，命中即停；lottery_winners.spinId 有联合索引可走
- **验证**：`tsc --noEmit` 0 errors，`spin-execution.test.ts` 23 tests passed

### M4. 3 个死代码函数清理
- **文件**：`src/lib/http.ts`（getOrigin）、`src/lib/activity-config.ts`（normalizeActivityConfigForStorage）、`src/services/payment/payment-status.ts`（isFulfilledOrderItemStatus）
- **改动**：删除无调用点的函数（git 历史可恢复）
- **原因**：死代码增加维护负担，无法覆盖测试
- **验证**：`tsc --noEmit` 0 errors，确认无调用点
