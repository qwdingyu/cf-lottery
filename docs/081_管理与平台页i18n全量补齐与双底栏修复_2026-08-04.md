# 081 管理与平台页 i18n 全量补齐与双底栏修复

日期：2026-08-04

## 背景

080 修复了奖品页「`$t` 有引用但缺命名空间」与平台租户详情布局挤压。审计发现同类问题仍大量存在：

1. 静态 `$t` 缺词条（会显示 key 原文）
2. 多个管理/平台页 template 零 `$t`，切 EN 仍全中文
3. `AdminModal` 默认底栏 + 内容区自带 `modal-actions` 形成双底栏
4. `ViralLeaderboard` 把 `$t('...')` 写成了未插值的纯文本

## 原因

- 页面先用硬编码中文落地，i18n 只覆盖了核心路径（活动/登录/奖品/租户）
- `AdminModal` 默认 `hideActions=false`，调用方在 default slot 内再写 footer 未关闭默认 actions
- 裂变组件部分文案漏写 `{{ }}`

## 方案与改动

### 1. 缺失静态 key（zh + en 对齐）

- `adminLogin.or`
- `adminConfig.emailTest.emailPlaceholder`（`@` 写成 `{'@'}`，通过 message-compiler 校验）
- `lottery.emailCodeRequired` / `lottery.viralHeadline` / `lottery.retry` 等裂变与公开页补丁
- 布局：`adminLayout.menuPlatform` / 模拟横幅 / 语言标签；`platformLayout.menuDataCleanup`
- 运营台 ROI/待办：`adminDashboard.roi*` / `todos*` / `conv*`

### 2. 新增命名空间并接线

| 命名空间 | 页面 |
|---|---|
| adminBlacklist | AdminBlacklistView |
| adminMembers | AdminMembersView |
| adminIntegrations | AdminIntegrationsView |
| adminRedemption | AdminRedemptionCodesView（平台码池 UI） |
| adminQuota | AdminQuotaRedeemView |
| platformMembers | PlatformMembersView |
| platformWebhooks | PlatformWebhookDeliveriesView |
| platformAudit | PlatformAuditLogsView |
| platformCleanup | PlatformDataCleanupView |

### 3. 双底栏

对内嵌 `modal-actions` 的弹窗统一加 `hide-actions`：奖品、黑名单、成员、集成、兑换码、平台成员等（与租户详情、活动编辑一致）。

### 4. 其它

- LotteryView 错误重试由 `adminPrizes.retry` 改为 `lottery.retry`
- 系统配置高级折叠文案 i18n；邮件测邮面板按 `groupNameKey === 'email_service'` 判断，避免绑死中文 group 名
- ViralLeaderboard 修复字面量 `$t` 与硬编码中文
- GameResultModal 分享失败文案走 `lottery.shareLinkFailed` / `networkError`

## 验收

- `npx tsc --noEmit` 0 error
- `frontend` `vue-tsc --noEmit` 0 error
- `npx vitest run` 251 passed（含 i18n-message-sanity）
- `frontend` `npm run build` 成功
- 静态 `$t` 扫描：无「两边都缺」的叶子 key；模板可见 CJK 仅剩语言选项「中文」

## 建议

- 后续新页面默认先加 ns 再写 UI，禁止 template 硬编码业务文案
- 使用 `AdminModal` 自定义 footer 时必须 `hide-actions` 或 `#actions` slot
- 文案含 `@` 时用 `{'@'}` 字面量，避免 vue-i18n linked message 语法错误
