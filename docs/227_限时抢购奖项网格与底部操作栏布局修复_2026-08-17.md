# 限时抢购奖项网格与底部操作栏布局修复

日期：2026-08-17  
范围：`/admin/draws` 创建活动弹窗，限时抢购模板的奖项配置与底部操作栏。  
关联：`docs/212_活动创建奖项配置条件组合矩阵_2026-08-12.md`、`docs/226_admin_draws创建表单紧凑布局与输入边界规范_2026-08-15.md`。

## 背景

选择“限时抢购”模板后，活动使用即时结果配置时，奖项表头展示了“奖品、奖档名称、中奖份数、权重、概率、删除”六列，但每条奖项数据行按照四列布局渲染，导致输入框与表头不对齐。创建态底部操作栏还会把“保存草稿”自动排到下一行。

## 原因

1. `.tier-grid--instant` 与 `.tier-row` 使用相同的 CSS 选择器优先级，但基础 `.tier-row` 规则在后声明，覆盖了即时模式应有的六列 `grid-template-columns`。
2. 底部操作栏定义为三列网格；创建态同时渲染“创建就绪提示”、占位元素、取消和保存草稿四个子元素，使第四项进入隐式第二行。

## 解决方案

1. 使用 `.tier-header.tier-grid--instant` 和 `.tier-row.tier-grid--instant` 显式定义即时模式的六列网格，保证表头和数据行共享同一列结构。
2. 占位元素仅在不显示创建就绪提示时渲染。创建态为“提示、取消、保存草稿”三项，编辑态为“占位、取消、保存”三项，均严格匹配三列布局。

## 影响与验证

- 不改变限时抢购的奖品绑定、卡密校验、保存接口或发布门禁。
- 桌面端即时奖项的输入列与表头对齐；移动端仍复用现有两列降级布局。
- 底部取消和保存草稿按钮保持同一行；小屏保留提示独占首行、两个按钮等宽并排的既有规则。
