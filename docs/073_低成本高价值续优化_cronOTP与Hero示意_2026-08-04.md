## 一、ROI 选型（本轮做 / 不做）

| 候选 | 成本 | 价值 | 本轮 |
|------|------|------|------|
| Cron Bearer `!==` → 常量时间比较 | 极低 | 与密码/OTP 策略一致；运维入口 secret 前缀计时面 | **做** |
| 管理端注册 OTP 对齐参与页（规范化 + 满 6 位自动提交） | 低 | 055a P1 已在 LotteryView，登录/注册仍弱 | **做** |
| Landing Hero 诚实线框示意（非假截图） | 低 | 055a 视觉余量；caption 标明「示意」 | **做** |
| 真活动截图 asset / 录屏 | 中（需设计素材） | 更高信任 | **不做**（无素材不臆造） |
| 完整 CSP 三套 | 高 | 安全 | **不做**（中期） |
| 拆 AdminLotteryView | 高 | 可维护 | **不做** |
| 运维删 LOGTO secret | 运维动作 | 清理 | **不做代码**（wrangler 已注释提示） |

## 二、改动清单

### 1. Cron 密钥比较（`src/index.ts`）

- `/api/cron/draw`、`/api/cron/maintenance`：`token !== cronSecret` → `timingSafeEqualString(token, cronSecret)`  
- 空 token 仍直接拒绝  
- 单测：`api-unknown-route.test.ts` 断言比较语义；实现复用 `lib/crypto-compare`

### 2. OTP 输入（管理端 + 参与页共用）

- 新增 `frontend/src/composables/otp-input.ts` + vitest  
- `AdminRegisterView` / `AdminLoginView` 注册验证码：`one-time-code`、数字规范化、满 6 位自动提交、发码后 focus  
- `LotteryView` 参与 OTP 改为调用同一 `normalizeOtpDigits`（行为不变，去重）

### 3. Landing Hero 示意

- 纯 CSS 线框 + i18n caption「非真实截图」  
- **禁止**被解读为真实 Demo 后台；真实 Demo 仍走 `demo_public_slug`（071）
